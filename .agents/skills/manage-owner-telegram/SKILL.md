# Telegram владельца AutoStop

Все принятые входящие рабочего Telegram, включая владельца, веди по
[B2](../../../docs/agent/modules/B2.md) и полному [клиентскому скиллу](../manage-autostop-client/SKILL.md).
Указание из доверенного Codex привязывай к точному кейсу по [B4](../../../docs/agent/modules/B4.md).

Прочитай [порядок поручений владельца в Telegram](../../../docs/agent/references/manager-roles.md#поручения-владельца-в-telegram).
Личный аккаунт веди по [B3](../../../docs/agent/modules/B3.md), отправку и сверку — по [B1](../../../docs/agent/modules/B1.md).
Роли и пределы поручения — [M1](../../../docs/agent/modules/M1.md) и [M2](../../../docs/agent/modules/M2.md).
