# Публичные камеры Красноярска

Получать один свежий PNG только с камер в корневом белом списке
`docs/agent/public_camera_registry.json`. Выполнять браузерный захват только через
`scripts/capture_public_camera.py`: контроллер запускает отдельного
непривилегированного пользователя в короткоживущем systemd sandbox.

## Рабочий процесс

1. Открыть `docs/agent/public_camera_registry.json`.
2. Разрешить формулировку владельца без захвата:

   ```bash
   .venv/bin/python scripts/capture_public_camera.py --resolve "<улица, адрес или ориентир>"
   ```

3. При одном совпадении использовать его `key`. При нуле совпадений честно
   сообщить, что подготовленной камеры нет. При нескольких совпадениях показать
   короткий список точек и попросить уточнить; не угадывать.
4. Создать отдельный root-only временный каталог и один файл:

   ```bash
   install -d -o root -g root -m 0700 /run/autostop-public-camera-output
   frame_path=$(mktemp /run/autostop-public-camera-output/public-camera-XXXXXX.png)
   .venv/bin/python scripts/capture_public_camera.py \
     --camera "<key>" --output "$frame_path" --overwrite
   ```

5. Открыть полученный файл через просмотр изображения. Убедиться, что это
   содержательный текущий кадр, а не черный экран, заставка или ошибка.
6. Отправить владельцу изображение по абсолютному пути. Описывать только общую
   дорожную обстановку, погоду или свободно видимые условия подъезда/парковки.
7. После выдачи запланировать удаление точного файла через 10 минут и проверить,
   что частичные файлы не остались:

   ```bash
   systemd-run --quiet --collect --on-active=10m \
     /usr/bin/unlink -- "$frame_path"
   ```

## Безопасные операции

- Показать каталог без захвата:

  ```bash
  .venv/bin/python scripts/capture_public_camera.py --list
  ```

- При ошибке публичной страницы или кадра вернуть недоступность и остановиться.
  Не подставлять другой URL, номер камеры, browser path, заголовки доступа или
  прямую динамическую ссылку проигрывателя.

## Жесткие границы

- Делать ровно один кадр по явному текущему запросу; не опрашивать по расписанию.
- Не получать архив, видео, аудио или управление камерой.
- Не распознавать и не сообщать лица, номера автомобилей или маршруты людей.
- Не сохранять кадр, динамический player URL или содержимое потока в Git,
  документацию, Manager memory, логи или базу знаний.
- В долговременном реестре хранить только публичное название, устойчивый
  идентификатор провайдера, приблизительные координаты, поисковые псевдонимы и
  время последней успешной проверки.
