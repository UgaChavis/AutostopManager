# AutoStop Learning Loop

Использовать этот цикл как проверяемый рабочий контур, а не как повод переписывать инструкции после случайного сбоя.

## Выполнение

1. Получить `agent_bootstrap` и effective mode. В `work` выполнить обычную задачу; этот skill не запускать.
2. Выполнить задачу адаптивно: живые факты читать из CRM, Store или Gmail; технические факты сверять с нужными источниками; записи выполнять только через существующие contracts и readback.
3. Перед финальным ответом вызвать `post_run_review` с безопасной task signature, completion evidence и техническими refs.
4. Принять решение review:
   - `no_change` или проверенный успех — закрыть learning cycle;
   - `lesson` — применить короткий reusable lesson без сырых данных;
   - `repair` — воспроизвести проблему, исправить минимальный слой, добавить regression test, проверить и повторить исходный шаг;
   - `defer` — зарегистрировать кандидат, использовать fallback и сообщить только важный для действия статус.
5. Закрыть cycle через `agent_learning_workflow`. Stop hook не должен продолжать ход, пока у completed review есть pending candidate; каждый кандидат должен быть `promoted`, `deferred` или `rolled_back`.

## Ограничения

- Не сохранять prompt, CRM/Gmail/Store payload, VIN, телефон, письма, заказы, суммы или секреты в опыте.
- Не превращать самооценку модели в постоянное правило без readback, повторного успеха, regression test или прямого сигнала владельца.
- Не лечить внешний timeout, CAPTCHA или отсутствие доступа случайным patch. Использовать fallback и health/deferred status.
- Не выполнять платёж, кассовую операцию, возврат или изменение финансового итога без прямого указания владельца.
- В Plan mode выполнять только review без repair, write или deploy.
