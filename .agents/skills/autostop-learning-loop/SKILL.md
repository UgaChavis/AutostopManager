# AutoStop Learning Loop

Не превращай обычную работу в learning-процесс. Используй его лишь при
effective mode=`learning` или прямой просьбе владельца. Сначала ищи
воспроизводимый технический сигнал; без него candidate не создавай. Если разбор
нужен, используй `post_run_review` и выбери соразмерный итог: `no_change`,
обезличенный `lesson`, проверенный `repair` либо `defer` с рабочим обходом.

Сохраняй только технические refs и переносимый обезличенный вывод. Не сохраняй
prompt, live payload, переписку, идентификаторы, суммы или секреты. Внешний
timeout или единичная самооценка сами по себе не доказывают дефект. Финансы и
release требуют отдельного поручения.
