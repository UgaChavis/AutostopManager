# CRM, подбор и Store AutoStop

Для клиентского обращения прочитай целиком [клиентский скилл](../manage-autostop-client/SKILL.md): он определяет общение и ведение сделки. Для операций используй [F2 — Store](../../../docs/agent/modules/F2.md) и нужные технические модули через [A1](../../../docs/agent/modules/A1.md).

Прямые поручения владельца выполняй по соответствующим техническим модулям в пределах запроса и общих полномочий [AGENTS.md](../../../AGENTS.md).
