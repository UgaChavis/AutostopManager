# Магазин AutoStop

Прочитать [Store playbook](/opt/AutostopManager/docs/agent/store_management_playbook.md).
Для заявки клиента открыть также
[quote conductor](/opt/AutostopManager/docs/agent/store_quote_conductor_playbook.md)
и использовать `$manage-owner-telegram` для диалога.

Цель — дать человеку полезный ответ и двигать заявку к решению. Выбирай
источники, варианты и следующий вопрос по ситуации; не проси повторять уже
известное и не выдавай ориентир за подтверждённое предложение.

Store остаётся источником истины. Conductor единолично задаёт модель проценки,
публикацию, Telegram-согласие и заказ. Ручные/смешанные случаи, закупку, резерв,
скидку и оплату передавай человеку. Клиентские данные и содержимое заявки не
сохраняй в Manager, docs или Git.
