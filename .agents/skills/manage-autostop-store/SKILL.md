# Клиентский кейс

Для клиентского обращения найди существующую CRM-карточку либо создай одну в
колонке заказов запчастей, разрешённой по живой CRM. Не создавай дубль и не перемещай
карточку при уточнениях. Клиент и автомобиль — в предназначенных полях; описание —
потребность, факты машины, OEM/аналоги, источники, предложения с датой проверки,
противоречия, ответ клиенту и следующий шаг. Сохраняй историю; перечитай после записи.

Перед длительным поиском коротко подтверди приём данных и продолжай до ответа
по результатам. «Принял» и ошибка инструмента не завершают работу. При ожидании
укажи конкретный вопрос, при задержке — содержательное обновление.
[Telegram skill](../manage-owner-telegram/SKILL.md) определяет запуск и отправку.
Общие заявки Store — отдельный охват; только по поручению на дежурство проверяй
их раз в 300 секунд средствами ожидания, сохраняя следующий шаг при остановке.

## Исследование и ремонт

Выбирай доступные источники по пользе для запроса: VIN/frame, OEM/EPC, интернет,
Emex, Exist, каталоги производителей, PartSouq/Amayama. Даже успешный VIN-поиск
сверяй независимо; отсутствие API не исключает публичный сайт.
`catalog_provider_status` показывает доступность конкретных операций, не успех
расшифровки; используй точные имена из схемы инструмента. Ошибка/пустой ответ
не доказывают отсутствие детали — уточни пробел и смени подходящий источник.

Извлекай модель, дату выпуска, двигатель, коробку, рынок и комплектацию; сверяй
номер, замены, условия установки, сторону, размеры и комплектность. Не выдавай
гипотезу за факт; копии одного каталога — не независимые подтверждения.
Справочники: `docs/agent/vin_oem_sources.json`, `docs/agent/partsapi_category_index.json`.
До заказа применимость проверяет человек.

Диагностику сверяй с официальными материалами нужной модификации и рынка;
жидкости — с агрегатом, допуском и объёмом. До диагностики стоимость ремонта
предварительная. План «установить после поступления» не подтверждает слот:
нужен приход детали или надёжно подтверждённая дата.

## Предложение

Сверяй точный бренд/артикул, количество, цену, наличие и срок. Не смешивай
розничный ориентир с закупкой, детали с работами; условия и скидки — из текущей
политики Store. Черновик не разрешает публикацию, резерв или закупку.
Перед разрешённой публикацией перечитай всю проценку, включая VIN; заказ требует
согласия с актуальным предложением. Намерение заплатить не означает оплату.
