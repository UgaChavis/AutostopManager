# E1 — VIN и подбор

E1 — набор независимых инструментов для определения автомобиля, поиска номера детали, проверки кандидатов, поиска аналогов и оценки рынка. Codex сам выбирает нужные действия по задаче и может вызывать их в любом порядке. Инструменты Manager доступны через D1; актуальные параметры каждого вызова смотри в его схеме.

## E4 — Определить автомобиль

`decode_vehicle_identity` принимает VIN или номер кузова и, при наличии, известные характеристики машины. Возвращает профиль автомобиля, источники, уверенность, противоречия и сведения, которые ещё нужны для подбора. `decode_vehicle_identities` делает то же для списка идентификаторов. Если требуется только расшифровка VIN, дальнейший подбор не нужен.

## E5 — Найти оригинальный номер

`lookup_original_parts` принимает идентификатор автомобиля и описание детали: название или группу, сторону, положение и известный старый номер. Возвращает план каталожной проверки, кандидатов OEM и недостающий контекст; само по себе не подтверждает оригинальный номер. Для запроса к PartsAPI выбирай нужную операцию `partsapi_catalog_lookup`. `resolve_vin_oem_parts` может собрать кандидатов по VIN и детали через один конкретный каталожный маршрут; это необязательный составной инструмент, а его результат не подтверждает OEM или применимость.

## E7 — Проверить сведения о детали в интернете

`verify_oem_candidates_web` принимает уже найденные номера и обезличенные характеристики автомобиля, сопоставляет кандидатов с публичными источниками и показывает расхождения. Он не принимает VIN; сетевой поиск включается отдельным параметром. Для самостоятельного поиска и чтения публичных страниц доступны `search_web_multi` и `fetch_page_excerpt` через E8. Публичная страница помогает проверить номер и характеристики, но не доказывает применимость к конкретному VIN.

## E6 — Подобрать аналоги

По известному номеру `public_aftermarket_catalog_lookup` ищет каталожные аналоги у поддерживаемых производителей; `exist_price_lookup` показывает публичные варианты и розничный ориентир; `search_offline_parts_catalogs` ищет совпадения в локальных каталогах без полного VIN. `partsapi_catalog_lookup` позволяет обратиться к подходящей операции каталога. Результаты этих команд — кандидаты: условия установки на конкретный автомобиль проверяются отдельно по надёжному каталожному источнику.

## E9 — Оценить рыночную стоимость

Собери сопоставимые публичные предложения по точному артикулу, бренду, состоянию и региону через E8, каталоги или доступные источники объявлений. `assess_part_market` принимает собранные предложения и рассчитывает ориентир только при достаточном числе независимых сопоставимых источников; сам предложения не ищет. Ориентир не означает наличие у поставщика и не становится ценой для клиента автоматически.

E2 — внешние источники vPIC и PartsAPI; E3 — каталоги и поставщики; E8 — шлюз публичного веба. Они дают данные отдельным инструментам E1, но не задают обязательный порядок работы. Для реального предложения клиенту отдельно проверяй применимость, актуальное наличие и цену в системе, которой принадлежит предложение.
