# D5 — Документация, навыки, обезличенный опыт

D5 описывает содержимое файловой части [D3](D3-storage-draft.md). Это материалы для выполнения задач, а не единый каталог записей с универсальной командой поиска.

- `AGENTS.md` задаёт действующие общие правила проекта; пробный пакет рядом с проектом сам по себе их не заменяет.
- `docs/agent/` и другие документы `docs/` описывают операции, модули, каталожные источники и проверки. Перед применением технических деталей сопоставляй документ с текущим кодом и схемой инструмента.
- `.agents/skills/` содержит инструкции для отдельных видов работы. Открывай подходящий навык по задаче.
- `data/private_knowledge/service_labor_experience.json` содержит обезличенные агрегаты опыта по работам, которые может использовать специальный инструмент оценки; частные отчёты и резервные копии не служат общей памятью агента.

Выбор и чтение материалов описаны в [D4](D4-knowledge-search-draft.md). Не помещай живые карточки клиентов, переписку, секреты и финансовые записи в общую документацию или память Manager.
