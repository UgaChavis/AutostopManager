# D2 — Знания и память

D2 объединяет способы найти технические инструкции и использовать ранее сохранённый обезличенный опыт. Это логический модуль карты, а не одна команда Manager MCP. Codex выбирает источник по вопросу: действующие инструкции и код проекта читает через A3 — терминал, а содержимое хранилища описано в [D3](D3-storage-draft.md).

## Что доступно сейчас

- [D4 — Поиск знаний](D4-knowledge-search-draft.md): поиск файлов документации, навыков и технических заметок, затем чтение нужного фрагмента. Общего инструмента D1 для такого поиска среди текущих команд нет.
- Отдельный инструмент D1 `estimate_repair_work_cost` при соответствующем параметре может использовать локальный обезличенный опыт по стоимости работ. Это частный источник для оценки работ, а не поиск по всей памяти.
- CLI `knowledge-sync` и `knowledge-audit` проверяют локальную документацию без записи базы; название `sync` не означает пополнение знаний.

## Как использовать

Найди относящиеся к задаче правила или технические сведения, проверь их актуальность по коду и доступным инструментам, затем используй в решении. Сведения из памяти не подменяют живые данные CRM, Store и внешних источников. Для будущей записи технического вывода нужны отдельные правила обезличивания и конкретное место хранения; сам D2 не предоставляет универсальной команды записи.
