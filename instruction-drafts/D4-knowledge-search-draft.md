# D4 — Поиск знаний и технической памяти

D4 — задача поиска подходящих инструкций и проверенных технических сведений внутри [D2](D2-knowledge-memory-draft.md). В текущем Manager MCP отдельной команды D4 нет. Codex выполняет поиск через A3 — терминал: находит файлы по имени или содержимому, открывает нужный документ и сверяет его с текущим кодом либо живой схемой инструмента.

Для документации проекта начни с `AGENTS.md`, `docs/agent/` и подходящего навыка в `.agents/skills/`; для технического вопроса ищи также профильные документы в `docs/` и исходники. Используй `rg --files` для списка файлов и `rg -n` для точного фрагмента. Результат поиска — источник и его контекст, а не подтверждение, что описанная возможность включена в установленном сервере.

Обезличенные агрегаты опыта по работам доступны через специальную оценку стоимости в D1. Этот вызов не заменяет поиск инструкций и не даёт доступа ко всем файлам [D3](D3-storage-draft.md).
