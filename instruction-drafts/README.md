# Черновики инструкций AutoStop Manager

Это отдельная папка репозитория для обсуждения нового пакета инструкций.
Файлы здесь являются черновиками и не подключены к действующему AutoStop Manager.

Принцип работы над пакетом: инструкции должны быть короткими, мягкими и оставлять агенту широкую свободу действий.
Обозначения A1, C2 и C3 соответствуют действующей карте модулей CRM; при развитии черновиков сверяй их с картой.

Пока структура и тексты нового пакета не согласованы. Добавляем и обсуждаем их
по одному; применение к проекту будет отдельным шагом после решения владельца.

Следующий проход по A1: для каждого модуля подобрать короткую пометку в скобках о том, когда его использовать.
