# CRM: Магазин автозапчастей

Колонка CRM имеет постоянный ID `parts_store`. Её видимость в браузере — личная настройка пользователя; карточки остаются в CRM и доступны менеджеру независимо от того, скрыта колонка или открыта.

Нативный инструмент Manager `parts_store_cards` поддерживает `list`, `get`, `create` и `append_note`. Он всегда ограничивает поиск колонкой `parts_store`, перед записью сверяет ID и текущую колонку карточки, а заметку дописывает к описанию с `expected_updated_at`. Для `create` и `append_note` нужен уникальный `idempotency_key`; после записи инструмент перечитывает карточку. При неопределённом исходе нельзя повторять запись вслепую — сначала найти карточку или перечитать её.

Данные клиентов, автомобилей и заметки хранятся только в CRM. Этот инструмент не меняет карточки других колонок, не создаёт заказ, не публикует предложение и не выполняет покупку. Для работы требуется настроенное локальное соединение Manager → CRM Gateway (`AUTOSTOP_CRM_MCP_URL`, `AUTOSTOP_CRM_MCP_BEARER_TOKEN`) и разрешённые CRM Gateway записи.
