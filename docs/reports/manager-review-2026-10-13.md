## Забег 002 — ядро и MCP

База: `efb6ca2ac3bcd7ee62265c8bb4e514f306258fc2`. Проверены native MCP registration,
валидация исходных JSON-аргументов, исполнение синхронных backend, проверка сервера
и общий технический журнал выполнения. VIN-поля проверяются только на границе MCP
с синтетическим decoder; VIN/OEM-реализация и параллельные пользовательские изменения
не входят в этот diff. Изменения общего `storage.py` ограничены транзакциями Manager run ledger.

| ID | Подтверждённая проблема | Исправление |
| --- | --- | --- |
| CORE-01 | Синхронные web и automation callbacks останавливали event loop native MCP | Ограниченные process-wide очереди; управление изолировано от веб-ожиданий, отмена сохраняет слот реального worker |
| CORE-02 | Probe мог зависнуть при ожидании ответа или записи в MCP stream | Полные deadline запросов и session RPC timeout; browser override сохраняется |
| CORE-03 | `tools/list` допускал циклы cursors и бесконечные страницы | Общий deadline, проверка cursor и предел 64 страниц с приёмом последней допустимой страницы |
| CORE-04 | SDK превращал bool и числовую строку в `expected_revision` | Проверка исходного JSON-типа до вызова controller; вложенный payload остаётся совместимым |
| CORE-05 | Строка `"null"` обходила строгие необязательные скалярные поля | Исходный тип четырёх strict полей сохраняется; вложенные options продолжают декодироваться |
| CORE-06 | Manifest принимал bool-count, дубликаты и числовые имена | Проверка исходных типов и уникальности до нормализации |
| CORE-07 | Concurrent external-step dedup возвращал новую step со старой run version | Run, CAS и step читаются в одной write transaction, включая идемпотентный ответ |

Регрессии используют настоящую FastMCP/ClientSession с синтетическими callbacks и
peer в памяти. До исправлений воспроизведены блокировка независимого запроса,
coercion revision/null, пропущенный timeout, неограниченная pagination и смешанная
версия журналирования. Проверяются корректные null/числа, JSON-вложенные аргументы,
заполненная очередь, отменённые ожидающие и выполняющиеся callbacks, независимость
управления, обычная pagination и граница 64 страниц, timeout handshake/call и
конкурентное повторение с CAS и без него. Публичные input schemas, SQLite schema
и действующие ключи идемпотентности сохраняются. Неизвестный исход уже начатого
backend остаётся основанием для сверки результата, без автоматического повтора.

## Забег 003 — веб и J1

База: `0cb1e0eb457e8d5a44c6dbc67659690c20a39a4e`. Проверены общий веб-фасад,
обычные J1 jobs и отчёты, static HTTP, OCR и локальный browser IPC. VIN-реализация
не меняется; совместимость общих helpers проверяется на изолированных данных.

| ID | Подтверждённая проблема | Исправление |
| --- | --- | --- |
| J1-01 | Веб-фасад передавал приватные URL и секретные queries, запрещённые прямым J1 | Общие URL/contact/secret guards до адаптера и при выдаче текста, с сохранением прежнего VIN-strip и артикулов |
| J1-02 | Ранняя остановка OCR завышала число обработанных страниц | Учитываются только страницы, прошедшие OCR |
| J1-03 | Backfill canonical URL оставлял transaction и откатывался при закрытии SQLite | Миграция завершается до доменной транзакции |
| J1-04 | Завершение worker перезаписывало принятую отмену или оставляло pending queries в completed job | Выбор следующей работы и завершение сериализованы с cancel/add_queries |
| J1-05 | Алиасы и redirect одного источника завышали независимость и confidence | Подсчёт authority использует canonical URL и существующие доменные алиасы |
| J1-06 | Допустимый Unicode-текст превышал старый response byte cap | Общий конечный IPC cap покрывает JSON encoding прежних символьных лимитов |
| J1-07 | Socket idle timeout пропускал длительный ответ по одному байту | Deadline на каждый raw HTTP read, включая headers/chunks/trailers; явное закрытие response |
| J1-08 | Symlink loop release-root падал вместо structured unavailable | RuntimeError разрешения пути возвращает прежний unavailable result |
| J1-09 | Заголовок неизвестного PDF превращал heuristic в доверенный B/high | Обычный report ограничивает heuristic D и отмечает отсутствие проверки authority |
| J1-10 | Допустимый Unicode URL превышал старый request byte cap | Общий конечный request cap и проверка размера до открытия socket |
| J1-11 | Ordinary tests и release gates оставляли рабочий VIN-cache доступным служебной очистке | Все J1 cache paths изолированы до gate callbacks; ordinary fixture задаёт отдельный private root |

Регрессии воспроизводятся до исправлений на временной SQLite, синтетических adapters,
OCR/subprocess stubs и настоящем HTTP/TLS parser через socketpair. Проверены отмена
и добавление запросов при завершении, legacy migration, известные Denso/Bosch A/B,
authority aliases, контакты/секреты/частные URL, обычный Renault article и VIN-strip,
Unicode URLs/text, oversized IPC, symlink loop, медленные headers/body/chunks/trailers,
корректная HTTP framing, parser failures и закрытие непрочитанного response. Сам gate shell
проверяется inert callbacks при унаследованных runtime paths; ordinary worker housekeeping
проверяется защитной заглушкой, запрещающей путь вне disposable cache.
TLS проверяет одноразовый локальный сертификат и исходное имя сервера; внешняя сеть
и рабочие browser/OCR services не используются.

Прогоны до исправления изоляции без private-root override не используются как доказательство
изоляции: они могли вызвать штатный prune рабочего VIN-cache; фактический эффект неизвестен.
После обнаружения проверки остановлены, пробел изоляции исправлен, финальная приёмка
повторена только на disposable paths и synthetic data.

Публичные MCP-схемы, бизнес-правила и browser wire protocol сохраняются. HTTP deadline
ограничивает отдельный обмен, не DNS, все robots/redirect checks или rate-limit ожидания.
Фактический final URL браузера требует отдельного доказательства: текущий renderer
возвращает запрошенный URL, поэтому гипотеза о redirect provenance не объявлена исправленным багом.
Общая приёмка — полный `release-gates.sh`, независимый окончательный review и GitHub CI
точных версий PR и основной ветки; публикация и установка остаются отдельными действиями.

## Забег 004 — каталоги, рынок и стоимость работ

База: `b781c35a3f794beb7f57b4e784a38d68194e6812`. Проверены локальный поиск каталогов,
чистая оценка переданных рыночных наблюдений, public labor acquisition и legacy estimator.
Registry routes, исходные файлы каталогов и клиентские записи не читаются как live data;
VIN/OEM implementation и пользовательский WIP сохраняются.

| ID | Подтверждённая проблема | Исправление |
| --- | --- | --- |
| CAT004-01 | Private hostname проходил как публичное ценовое свидетельство | Явные private host categories исключаются без DNS/fetch |
| CAT004-02 | Обычный текст `[PAGE N]` менял страницу и OCR-признак PDF | Marker распознаётся только в полном служебном формате; старые form feeds сохраняются |
| CAT004-03 | Symlink loop обрывал весь поиск локальных каталогов | Root возвращает существующую ошибку; bad text entry пропускается с incomplete status |
| LABOR-01 | Знак терялся в строковых ценах/часах, большие числа обрывали расчёт | Сохраняются sign/finite guards, включая отрицательные диапазоны и переполнение вычислений |
| LABOR-02 | Повторные quotes искусственно достигали порога выборки | Identity dedup после source adaptation; parts conflicts объединяются консервативно |
| LABOR-03 | Query intent становился наблюдаемой операцией для чужой цены/времени | Работа, сумма/часы и scope связываются в локальном тексте источника |
| LABOR-04 | Body-read ConnectionResetError выходил из legacy collector | Transport fault сохраняется в существующем source failure path |
| LABOR-05 | Явный time cross-check conflict сохранял высокий decision confidence | Existing conflict учитывается при confidence; диапазон и ценовая формула сохраняются |
| LABOR-06 | Legacy поля передавали VIN/контакты/секреты в общий DDG search, а новый collector пропускал секреты | Общий guard до HTTP, безопасный query plan и полное обезличивание явно переданных идентификаторов |

Дефекты воспроизводятся на temporary catalog text/index, реальных symlinks, supplied
observations и fake HTTP responses через настоящий parser/collector/estimator.
Проверки запрещают live provider и implicit production experience reads. Positive controls
сохраняют public price evidence, form-feed pages, здоровый каталог рядом с плохим,
известные цены/часы и согласованный трёхкомпонентный evidence bundle.
Дополнительный проход сохраняет title-only основание с одной однозначной ценой/нормой
времени в snippet, включая parts veto; чужая работа и несколько сумм/часов
не наследуют заголовок. Ограничение confidence относится к явным `too_high/too_low`,
а существующая выбранная часовая ставка сохраняет прежнее поведение.
Длинные нечисловые строки проверяются отдельным процессом с deadline и запретом
provider/private reads. Переполнение производной ставки сохраняет уже доказанный
`too_high` через сравнение цены и часов с прежним порогом, не через новое ограничение цены.
Известный ноль вычисленной ставки сохраняется для прежнего `too_low`.
Privacy-проверка проходит реальный estimator/collector/DDG parser с fake HTTP response:
все свободные query-поля, encoded secrets, явно переданный VIN и короткий номер кузова,
безопасный план запросов, отсутствие отражения отклонённого текста и healthy public controls.
Общий checker J1 распознаёт quoted secret keys без отдельного слоя в labor callers;
literal replacement учитывает смешанный регистр, а числовой идентификатор в поле года
обезличивается только как vehicle metadata. Цены, ставки, счётчики и обычный год сохраняют тип.
Проверка не устанавливает историческую утечку клиентских данных.

География города/края, независимость издательских субдоменов, public-quote TTL и locale
денежного separator не меняются без подтверждённого контракта. Изоляционный риск ранних
проверок из забега003 относится ко всем прежним прогонам без private-root override;
фактические эффекты служебного expiry cleanup не установлены. Новые проверки используют
оба disposable J1 paths до callbacks. Публикация требует независимой окончательной
приёмки, полного `release-gates.sh` и CI точных head/main SHA.
