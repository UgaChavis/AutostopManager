# E7 — публичная проверка OEM-кандидатов

`verify_oem_candidates_web` принимает уже найденные OEM-кандидаты и профиль детали: марку, модель, год, двигатель, ось, сторону и позицию. VIN-поля нет: VIN-подобный текст, включая варианты с `/`, `_`, `.` и `-`, вырезается из запросов; VIN вместо номера отклоняется.

По умолчанию `live_search=false`: внешних вызовов нет. При явном включении E7 передаёт обезличенный запрос в `WebResearchGatewayV1` с операцией `research_part_public_evidence`. E8 — единый read-only шлюз — ищет только по четырём каноническим публичным источникам: PartSouq, Amayama, Emex и Exist; он возвращает не более пяти кандидатов и двух коротких выдержек. E7 дополнительно сверяет идентификатор источника, тип и домен с локальным статическим набором. Если в процессе пока не установлен аутентифицированный клиент E8, используется явно помеченный ограниченный fallback DuckDuckGo.

Маршруты источников берутся только из `docs/agent/automotive_sources/automotive_repair_sources_catalog.json` с `include_licensed=False`; маршруты с оплатой, входом, регистрацией или подпиской не возвращаются. На кандидата возвращаются OEM-номер, имя, ссылки/источники, условия применимости, противоречия, статус и следующий ручной шаг. Сбой шлюза становится структурированным `search_failed` без текста внутренней ошибки.

E7 не выдаёт `подтверждён` по переданной ссылке или веб-сниппету: они остаются `кандидатами` до доверенной EPC-проверки применимости. Конфликт или неудачная проверка дают `не подтверждён`. Инструмент ничего не записывает в CRM, не создаёт заказов и не делает покупок.
