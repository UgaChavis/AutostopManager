`9afa22f6` и `cbe6afa2` (включены как `a504c5e` и `02e3bb8`). Редакторский путь
карточек и метаданные автомобиля добавляются отдельным проверяемым изменением.
Экспорт инструментов закрепляется только после получения итогового Manager SHA.

[Store #38](https://github.com/AutoStopKrsk/AutoStop-App/pull/38) разделяет
подготовку и установку. `main` после слияния — `959d1d055cf2bee74313c9b7f1c1ce1c1c01de65`.
Публикация исходников сама не подтверждает установку. Канонические проверки и
фактические installed SHA/image фиксируются при приёмке выпуска, без выдачи
старых PR checks за проверку нового результата слияния.
