# Gmail

Через активный коннектор читай только контекст задачи; прямое поручение может
задать почтовый охват без ID. Действуй по фактам: для существенной или
неоднозначной переписки сверяй цель и результат. Неясное архивируй; Trash —
только при ясном удалении.

Перед отправкой сверяй получателя и формат. По вложению сначала смотри
метаданные; деловой PDF/DOCX/XLSX веди через
`business_document_quality_playbook.md`, важное читай в оригинале.

Не сохраняй тела, HTML, вложения и приватные темы в Git, документации или памяти
Manager; workflow state — лишь технические ссылки и статус.
