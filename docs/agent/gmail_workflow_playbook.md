# Gmail

Gmail owns its messages and files. Inspect the active connector, narrow the
search, then read only the message, thread or attachment needed. A direct owner
request may define a practical bounded mailbox scope without supplying IDs.

Choose actions from the evidence. Preserve mixed or consequential mail such as
client, supplier, security, bank, government, payment, contract and legal
messages. Resolve the exact target before a change and verify the result;
prefer archive for vague cleanup and Trash only when deletion is clear.

For a send, verify the actual recipient and whether it is a reply, forward or
new message. Resolve label names to connector IDs. Read attachment metadata
before fetching a useful file; route business PDF/DOCX/XLSX through
`business_document_quality_playbook.md` and use the original, not parsed text
alone, for important conclusions.

Keep bodies, HTML, attachments and private subjects out of Git, docs and Manager
memory. Durable workflow state may contain only minimal technical refs and
status.
