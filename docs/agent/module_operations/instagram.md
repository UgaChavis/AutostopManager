# Рабочий Instagram через Windsor.ai

Назначение: читать рабочий профиль, публикации, сторис и комментарии; готовить и
выполнять только прямо порученные владельцем публикации и ответы. Источник данных
и результата — Instagram. Manager не хранит копию ленты или переписки.
Правила адресата, публикации и повторной проверки: [Instagram skill](../../../.agents/skills/manage-owner-instagram/SKILL.md).

Вход: поручение владельца и ровно один актуальный аккаунт из `get_connectors`.
Далее `get_fields` → `get_data` для чтения; `list_actions` → разрешённое
`execute_action` → независимое чтение для записи. ID и схемы берутся из текущего
ответа, не из документа. Выход — прочитанные данные либо подтверждённая публикация
или комментарий. Медиа для записи должны быть доступны по URL по актуальной схеме.

Проверка 2026-09-26: интерактивный коннектор разрешил чтение профиля, списка
публикаций и метаданных комментариев. Обнаружены девять действий: фото, карусель,
Reels, сторис, создание/ответ/скрытие/восстановление/удаление комментария. Это
доказательство чтения и схем, а не успешной записи. Тестовые публикации в рабочем
аккаунте запрещены объёмом технического выпуска. Direct и Instagram event trigger
не предоставлены текущим коннектором.

В существующем фоновом чате Telegram `app/list` показал доступный Windsor,
`mcpServerStatus/list` — его инструменты чтения и записи. Реальный read-only `get_connectors`
прошёл и в этом чате, и в отдельном `codex exec --ephemeral --sandbox read-only`.
Не запускайте публикацию для проверки доступа; чтение не доказывает запись.
Схема App Server: [официальная документация](https://developers.openai.com/codex/app-server).
Для отдельного CLI окружения повторите discovery с его cwd и конфигурацией.

Типовые ошибки: нет/несколько аккаунтов → остановить выбор цели; permission error
→ проверить доступ через форму подключения плагина; пустой список → сверить поля,
период и ограничения выбранной таблицы. Полученный период проверяйте по timestamp:
таблицы медиа могут возвращать историю шире заданного окна. Отсутствие актуальных
сторис допустимо, поскольку они доступны ограниченное время. Неизвестный исход
записи сначала сверяйте по точной публикации, не повторяйте вслепую.

Связи: [Telegram](telegram_automation.md) для разрешённого рабочего канала,
[Store](store_adapter.md) для подтверждения коммерческих фактов,
[каталог модулей](README.md) и [выпуск](runtime_release.md). Установка Manager
не заменяет авторизацию внешнего аккаунта и не создаёт Instagram monitoring.
