# E7 — публичная проверка OEM-кандидатов

`verify_oem_candidates_web` принимает уже найденные OEM-кандидаты и профиль детали: марку, модель, год, двигатель, ось, сторону и позицию. VIN-поля нет: VIN-подобный текст, включая варианты с `/`, `_`, `.` и `-`, вырезается из запросов; VIN вместо номера отклоняется.

По умолчанию `live_search=false`: внешних вызовов нет. При явном включении выполняется только ограниченный поиск по номеру; redirect `uddg` распаковывается локально без запроса. В результат попадают только ссылки на публичные бесплатные хосты из реестра; сниппеты остаются слабой справкой и никогда сами не дают статус `подтверждён`.

Маршруты источников берутся только из `docs/agent/automotive_sources/automotive_repair_sources_catalog.json` с `include_licensed=False`; маршруты с оплатой, входом, регистрацией или подпиской не возвращаются. На кандидата возвращаются OEM-номер, имя, ссылки/источники, условия применимости, противоречия, статус и следующий ручной шаг.

E7 не выдаёт `подтверждён` по переданной ссылке или веб-сниппету: они остаются `кандидатами` до доверенной EPC-проверки применимости. Конфликт или неудачная проверка дают `не подтверждён`. Инструмент ничего не записывает в CRM, не создаёт заказов и не делает покупок.
