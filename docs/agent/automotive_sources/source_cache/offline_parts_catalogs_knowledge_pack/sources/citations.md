# Offline Parts Catalog Source Citations

Checked on 2026-06-05.

## MAN / OEM Boundary

- MAN official online ordering service says MAN works with partslink24, offers
  access to MAN Genuine Parts, identifies parts using the VIN, and can export a
  shopping basket to MANTIS, the electronic parts catalogue:
  <https://www.man.eu/global/en/service/online-ordering-service.html>
- partslink24 describes complete, up-to-date genuine-parts data from
  participating manufacturers and distinct part identification by VIN:
  <https://www.partslink24.com/>

Conclusion: MAN OEM lookup remains an authorized online/dealer route. Do not use
third-party MAN MANTIS downloads as source evidence.
