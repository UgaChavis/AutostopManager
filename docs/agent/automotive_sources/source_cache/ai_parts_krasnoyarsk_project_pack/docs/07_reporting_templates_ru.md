# 07. Шаблоны отчетов для менеджера автосервиса

## Принципы отчета

Отчет должен быть коротким, проверяемым и пригодным для действия. Менеджер должен понять:

1. Что именно найдено.
2. Почему это подходит.
3. Где купить.
4. Что надо проверить перед оплатой.
5. Какой риск остается.

## Шаблон: краткий отчет

```text
Заявка: {vehicle} / {part_name}
VIN: {vin_status}
OEM: {oem_number}
Уверенность применяемости: {fitment_score}/100

Рекомендация №1: {seller} — {brand} {article}
Цена: {price_rub} ₽
Доставка/получение: {delivery_text}
Наличие: {availability_text}
Гарантия/возврат: {warranty_return_text}
Итоговый рейтинг: {score}/100

Почему этот вариант:
{reasoning}

Проверить перед оплатой:
{checklist}

Резервные варианты:
1. {backup_1}
2. {backup_2}
```

## Шаблон: отчет по срочному поиску в Красноярске

```text
Режим: срочный поиск, Красноярск
Критерий: получение сегодня/завтра важнее минимальной цены

Найдено локальных вариантов: {local_count}
Подтверждено звонком: {confirmed_count}
Лучший вариант: {best_local_offer}

Комментарий:
Если клиент согласен ждать {days} дней, можно сэкономить примерно {saving_rub} ₽, но простой автомобиля увеличится.
```

## Шаблон: отчет по б/у/контрактной детали

```text
Тип детали: б/у/контракт
Критичные признаки: номер, маркировка, фото, гарантия, возврат

Лучший продавец: {seller}
Источник: {source}
Цена: {price_rub} ₽
Срок: {delivery}
Гарантия: {warranty}
Фото маркировки: да/нет
Видео проверки: да/нет
Совпадение номера: {match_status}

Риски:
- {risk_1}
- {risk_2}

Перед заказом запросить:
- фото маркировки крупно;
- фото креплений;
- гарантию в сообщении/счете;
- условия возврата;
- подтверждение комплектации.
```

## Шаблон: отчет по электронному блоку

```text
Электронный блок: {module_name}
Старый номер: {old_number}
Найденный номер: {found_number}
Аппаратная версия: {hardware_status}
Программная версия: {software_status}
Нужна привязка/кодирование: {coding_required}

Решение:
Покупать только при подтверждении возврата и совместимости. Если продавец не может подтвердить аппаратный номер, вариант считать рискованным.
```

## Шаблон: нет надежного результата

```text
Надежный результат не найден.

Причина:
{reason}

Что нужно уточнить:
1. {missing_1}
2. {missing_2}
3. {missing_3}

Следующие действия:
- проверить VIN-каталог;
- запросить фото старой детали;
- расширить географию;
- запросить поставщиков вручную;
- проверить разборки.
```
