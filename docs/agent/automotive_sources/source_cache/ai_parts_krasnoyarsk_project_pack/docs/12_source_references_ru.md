# 12. Справочник источников и что из них брать

## ZZap

Назначение: поиск по артикулу, статистика цен, ориентир рынка.

Что брать:

- статистику минимальной/медианной/максимальной цены;
- регионы;
- первичные ориентиры по наличию, если разрешено условиями.

Ограничение: не использовать для массового выкачивания актуальных предложений, если это запрещено правилами API.

## Forum-Auto

Назначение: B2B-поставщик с API для поиска товара, цен, сроков и остатков.

Что брать:

- бренд;
- артикул;
- название;
- цену;
- количество;
- срок;
- склад;
- возвратность.

## Laximo

Назначение: VIN-каталоги, оригинальные номера, замены, поиск по артикулу и естественному описанию.

Что брать:

- OEM-номер;
- заменители;
- применяемость;
- названия деталей;
- признаки оригинальности.

## TecDoc

Назначение: aftermarket-каталог, применяемость и аналоги.

Что брать:

- аналоги;
- бренды;
- применяемость;
- параметры детали;
- медиа и технические данные, если доступно.

## 2ГИС

Назначение: поиск локальных организаций.

Что брать:

- название;
- адрес;
- телефон;
- сайт;
- график;
- координаты;
- профиль деятельности.

Не брать: остатки товаров, потому что справочник их обычно не знает.

## Яндекс Карты / Организации

Назначение: поиск организаций, справочная информация, профиль продавца.

Что брать:

- название;
- адрес;
- телефон;
- сайт;
- график;
- рубрики;
- географию.

## Деловые Линии, СДЭК, Почта России

Назначение: расчет доставки и сроков.

Что брать:

- стоимость доставки;
- срок;
- возможность забора;
- статус отправки;
- ограничения по весу/габаритам.

## Авито, Дром, FarPost

Назначение: объявления б/у, контрактных, кузовных и редких деталей.

Что брать в безопасном режиме:

- поисковые фразы;
- ссылку на объявление;
- заголовок;
- цену;
- город;
- фото/маркировки;
- результат контакта с продавцом.

Не делать без разрешения:

- массовое скачивание;
- обход защиты;
- скрытый мониторинг;
- перепродажу данных.
