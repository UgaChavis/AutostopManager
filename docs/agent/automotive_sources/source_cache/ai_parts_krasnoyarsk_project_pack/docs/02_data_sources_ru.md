# 02. Источники данных

## Классификация источников

Источники делятся не по удобству, а по степени автоматизируемости и надежности.

| Класс | Примеры | Что дает | Автоматизация | Основной риск |
|---|---|---|---|---|
| OEM-каталоги и VIN-каталоги | Laximo, TecDoc, PartsAPI, дилерские каталоги | применяемость, оригинальные номера, кроссы | через договор/API | неполный VIN или неверная комплектация |
| B2B-поставщики | Forum-Auto, Rossko, Part-Kom, Autopiter, Emex, Armtek | цена, остаток, срок, склад | высокая при наличии договора | задержки, неверный кросс, пересорт |
| Агрегаторы | ZZap, Zaptrade, ABCP, Docpart | рыночная цена, первичная статистика, продавцы | ограниченная, по правилам источника | запрет массовой выгрузки предложений |
| Маркетплейсы объявлений | Авито, Дром, FarPost | б/у, контракт, кузов, агрегаты, редкие детали | ручная или официально разрешенная | устаревшие объявления, нет артикула, дубли |
| Карты и справочники | 2ГИС, Яндекс Карты | список локальных продавцов, адрес, телефон, график | через API по лицензии | источник не знает остатки |
| Логистика | Деловые Линии, СДЭК, Почта России, Boxberry | срок и стоимость доставки | через API | расчет не равен фактической отгрузке |
| Внутренняя база сервиса | история заказов, возвраты, успешные поставщики | надежность продавцов, подходящие кроссы | полностью | база должна регулярно чиститься |

## Приоритет источников

Для новой детали:

```text
VIN-каталог → OEM-номер → B2B API → агрегатор статистики → локальные магазины → маркетплейсы → звонок
```

Для б/у или контрактной детали:

```text
VIN/маркировка → фото старой детали → разборки → Дром/Авито/FarPost → локальные продавцы → видео/фото/звонок
```

Для кузовной детали:

```text
VIN → кузов/рестайлинг/сторона → цвет/код цвета → наличие креплений → фото → геометрия → гарантия возврата
```

Для электронного блока:

```text
VIN → номер блока → аппаратная версия → программная версия → кодирование/привязка → гарантия возврата → проверка на стенде/автомобиле
```

## Источники, которые нужно подключать первыми

### 1. VIN/каталожная идентификация

Без этого система будет искать похожие, но не обязательно подходящие детали. Минимум: Laximo или TecDoc, плюс ручной режим по оригинальным каталогам.

### 2. Один-два B2B-поставщика

Начать с поставщиков, у которых уже есть договор автосервиса. Цель — получить структурированный ответ: бренд, артикул, срок, количество, цена, склад, возможность возврата.

### 3. Локальные продавцы Красноярска

Собрать базу магазинов, разборок и профильных поставщиков по категориям: BMW, Toyota, VAG (Volkswagen Aktiengesellschaft — концерн Volkswagen), корейские авто, кузовщина, агрегаты, электрика, дизель, турбины.

### 4. Маркетплейсы объявлений

Авито, Дром и FarPost использовать как источник найденных вручную или разрешенно полученных кандидатов. Их не надо превращать в источник неподтвержденных «остатков».

### 5. Логистика

Для заказов не из Красноярска расчет цены без доставки неполон. В оффере должно быть поле `total_cost = price + delivery_cost + payment_fee + delay_cost`.

## Что хранить по каждому источнику

```yaml
source_id: forum_auto
source_type: b2b_api
legal_mode: contract_api
supports_stock: true
supports_price: true
supports_delivery_time: true
supports_fitment: false
requires_manual_confirmation: false
rate_limit_policy: from_contract
confidence_baseline: 0.82
```

## Матрица доверия

| Источник | Цена | Остаток | Применяемость | Фото | Комментарий |
|---|---:|---:|---:|---:|---|
| VIN-каталог | нет | нет | высокая | редко | не заменяет проверку фактического номера |
| B2B API | высокая | средняя/высокая | средняя | редко | остаток надо проверять по критичным заказам |
| Агрегатор статистики | средняя | низкая/средняя | низкая/средняя | редко | полезен для медианы рынка |
| Авито/Дром | средняя | низкая до звонка | низкая/средняя | высокая | хороши для б/у и агрегатов |
| 2ГИС/Яндекс Карты | нет | нет | нет | нет | полезны для поиска продавца, не товара |
| Звонок продавцу | высокая | высокая | зависит от вопросов | можно запросить | самый важный контроль перед заказом |
