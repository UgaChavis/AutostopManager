# 14. Модель проценки, усреднения и анализа рынка

## Задача

Проценка должна отвечать не только на вопрос «сколько стоит», но и на вопрос «какой вариант экономически разумен для ремонта».

## Раздельные ценовые корзины

Нельзя усреднять все предложения вместе. Нужно делить на корзины:

```text
OEM новая
OEM б/у
аналог премиум
аналог средний
аналог бюджетный
контрактная деталь
восстановленная деталь
локально в Красноярске
под заказ из России
```

Пример: новый оригинальный радиатор и б/у радиатор с разборки не должны формировать одну медиану.

## Минимальный набор статистики

Для каждой корзины:

```json
{
  "count": 12,
  "min_price": 8500,
  "median_price": 14200,
  "p25": 11800,
  "p75": 16900,
  "max_price": 26000,
  "trimmed_mean": 14850,
  "outliers": ["offer_id_7"]
}
```

## Почему медиана лучше среднего

Среднее значение портится выбросами: ошибочной ценой, отсутствующим товаром, демпингом, неполным комплектом или завышенной ценой. Медиана устойчивее.

## Алгоритм расчета медианы рынка

1. Собрать предложения одной корзины.
2. Удалить предложения без цены.
3. Удалить неподтвержденные предложения только для срочного режима.
4. Рассчитать медиану.
5. Рассчитать MAD (Median Absolute Deviation — медианное абсолютное отклонение).
6. Пометить выбросы.
7. Рассчитать `price_score`.

Псевдокод:

```python
median_price = median(prices)
mad = median(abs(price - median_price) for price in prices)
outlier = abs(price - median_price) > 3.5 * mad
```

Если предложений меньше 5, не удалять автоматически, а помечать статистику как слабую.

## Локальная премия Красноярска

Для срочного ремонта локальное наличие может быть дороже, но выгоднее.

```text
local_premium = local_price / remote_price_with_delivery
```

Если `local_premium <= 1.25` и деталь нужна сегодня, локальный вариант часто предпочтительнее.

## Стоимость простоя

```text
delay_cost = delivery_days * bay_idle_cost_per_day
```

Пример:

```text
локальная деталь: 25 000 ₽, сегодня
удаленная деталь: 19 000 ₽ + 1 000 ₽ доставка, 4 дня
стоимость простоя: 6 000 ₽/день
итог удаленной: 19 000 + 1 000 + 4*6 000 = 44 000 ₽
```

В этом случае локальная деталь дешевле для сервиса, хотя цена товара выше.

## Вероятность ошибки

Для рискованных категорий добавлять ожидаемую стоимость ошибки:

```text
expected_error_cost = error_probability * rework_cost
```

Примерные коэффициенты для старта:

```yaml
consumables: 0.03
suspension_brakes: 0.07
body: 0.12
powertrain: 0.18
electronics: 0.25
unknown_fitment: 0.35
```

Эти коэффициенты нужно переобучать на собственной статистике.

## Итоговая экономическая оценка

```text
economic_cost = part_price
              + delivery_cost
              + delay_cost
              + expected_error_cost
              - warranty_value
```

`warranty_value` не должен быть большим числом. Гарантия снижает риск, но не превращает плохой вариант в хороший.

## Проценка по России

Для поиска по России формировать три результата:

1. Минимальная цена с приемлемым риском.
2. Минимальный срок с приемлемым риском.
3. Баланс цены и срока.

Географические уровни:

```text
Красноярск
Красноярский край
Новосибирск/Иркутск/Томск/Кемерово
Урал
Москва/Санкт-Петербург
Владивосток/Дальний Восток
Россия целиком
```

## Когда нельзя давать ценовую рекомендацию

- меньше 3 сопоставимых предложений;
- нет точной применяемости;
- все предложения только из объявлений без звонка;
- разброс цен выше 70% и причина не ясна;
- деталь электронная или агрегатная, но нет номера/маркировки.

В таких случаях отчет должен говорить: «цена ориентировочная, нужна проверка».
