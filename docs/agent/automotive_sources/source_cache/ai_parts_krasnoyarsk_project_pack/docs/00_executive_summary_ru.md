# 00. Краткая концепция проекта

## Цель

Создать систему, которая помогает автосервису быстро находить автозапчасти:

- в наличии в Красноярске;
- с доставкой по Красноярскому краю;
- под заказ из России;
- контрактные и б/у детали через Авито, Дром, разборки и профильные магазины;
- новые детали через поставщиков, агрегаторы и B2B (Business-to-Business — бизнес для бизнеса)-API.

Система должна быть полезна менеджеру автосервиса: не только показать цену, но и снизить риск ошибочного заказа.

## Главный принцип

Запчасть нельзя искать только по названию. Надежный поиск начинается с идентификации:

```text
Автомобиль → VIN/Frame → узел → OEM-номер → производитель → артикул → замены/кроссы → предложения → подтверждение наличия
```

Если известен только текст вроде «радиатор BMW X5», агент должен сначала уточнить контекст: кузов, двигатель, год, VIN, сторона, система охлаждения/кондиционирования, оригинальный номер на старой детали, фото.

## Три слоя проекта

### 1. Слой идентификации детали

Задача: понять, что именно нужно купить.

Источники:

- VIN-каталоги: Laximo, TecDoc, PartsAPI, OEM (Original Equipment Manufacturer — производитель оригинального оборудования)-каталоги;
- кросс-базы и каталоги аналогов;
- фотографии старой детали и маркировок;
- данные автомобиля: марка, модель, год, двигатель, коробка, кузов, комплектация.

### 2. Слой поиска предложений

Задача: найти реальные предложения.

Каналы:

- B2B API поставщиков: Forum-Auto, Rossko, Part-Kom, Autopiter, Emex, Armtek и другие при наличии договора;
- агрегаторы: ZZap, Zaptrade, ABCP (Autoparts Business Cloud Platform — платформа для интернет-магазинов автозапчастей), Docpart;
- локальные магазины и разборки Красноярска;
- Авито, Дром, FarPost — особенно для контрактных, кузовных, агрегатных и редких деталей;
- 2ГИС и Яндекс Карты — для поиска продавцов, разборок и профильных магазинов;
- логистика: СДЭК, Деловые Линии, Почта России, Boxberry.

### 3. Слой принятия решения

Задача: выбрать не самое дешевое, а оптимальное предложение.

Параметры:

- точность применяемости;
- фактическое наличие;
- срок получения;
- итоговая стоимость;
- риск возврата;
- гарантия;
- надежность продавца;
- стоимость простоя автомобиля;
- возможность резервирования;
- фото и маркировки.

## Минимальный рабочий процесс

1. Получить заявку.
2. Нормализовать данные.
3. Определить точный артикул и кроссы.
4. Запустить поиск: локальный Красноярск, регион Сибирь, Россия, контракт/б/у, новые аналоги.
5. Свести предложения в единую таблицу.
6. Отфильтровать неподтвержденные и сомнительные.
7. Позвонить 2–5 лучшим продавцам.
8. Пересчитать итоговый рейтинг после звонка.
9. Отдать менеджеру короткий отчет с рекомендацией.

## Что система не должна делать

- обходить защиту сайтов;
- массово выгружать чужие объявления без разрешения;
- скрыто собирать персональные данные;
- выдавать неподтвержденное наличие как факт;
- выбирать деталь только по похожему названию;
- подменять VIN-зависимую проверку догадкой.

## Ключевая метрика эффективности

Система считается полезной, если снижает:

- время поиска;
- процент ошибочных заказов;
- долю заказов без подтвержденного наличия;
- количество возвратов;
- простой автомобиля на подъемнике.
