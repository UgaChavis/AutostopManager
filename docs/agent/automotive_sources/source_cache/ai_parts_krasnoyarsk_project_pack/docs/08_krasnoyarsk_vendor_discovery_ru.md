# 08. Поиск и ведение базы продавцов Красноярска

## Зачем нужна локальная база

API-поставщики хорошо решают задачу новых деталей. Но срочный ремонт, кузовные детали, агрегаты и б/у часто решаются через локальные магазины, разборки и узкоспециализированных продавцов.

Локальная база должна быть не справочником телефонов, а рабочим реестром надежности.

## Категории локальных продавцов

```yaml
categories:
  - universal_parts_store

```

## Как искать продавцов

### Через 2ГИС и Яндекс Карты

Поисковые фразы:

```text
автозапчасти Красноярск
авторазбор Красноярск
контрактные запчасти Красноярск
запчасти BMW Красноярск
запчасти VAG Красноярск
кузовные запчасти Красноярск
двигатели контрактные Красноярск
коробки передач контрактные Красноярск
турбины ремонт Красноярск
автоэлектроника блоки управления Красноярск
```

### Через маркетплейсы

Искать не только конкретную деталь, но и продавцов, у которых много объявлений нужной категории.

Признаки полезного продавца:

- много объявлений по одной категории;
- есть адрес/склад;
- есть фото именно товара, а не каталожная картинка;
- повторяются телефоны и названия;
- продавец дает гарантию;
- быстро отвечает;
- умеет работать с VIN и артикулами.

## Журнал контактов

Каждый звонок должен увеличивать качество базы.

```json
{
  "seller_id": "krsk_bmw_used_001",
  "called_at": "2026-05-03T14:30:00+07:00",
  "manager_name": "...",
  "request": "BMW F15 радиатор охлаждения 17118625482",
  "result": "нет в наличии",
  "promised_callback": false,
  "data_quality": "asked_vin_and_number",
  "notes": "умеют проверять по номеру, предложили аналог"
}
```

## Внутренний рейтинг продавца

```text
seller_score = base
             + successful_orders * 2
             - wrong_parts * 10
             - late_shipments * 4
             - refused_returns * 8
             + good_communication * 2
             + photo_marking_provided * 2
```

Рейтинг нельзя делать только по отзывам из интернета. Для автосервиса важнее собственная статистика: подошло/не подошло, вернули/не вернули, задержали/не задержали.

## Порядок наполнения базы

1. Собрать 50–100 организаций из 2ГИС/Яндекс Карт по категориям.
2. Присвоить категории.
3. Позвонить 20 ключевым продавцам и уточнить специализацию.
4. Добавить продавцов из успешных заказов.
5. Раз в 30 дней обновлять телефоны, график, адрес.
6. После каждого заказа обновлять рейтинг.

## Минимальная база для старта

```text
10 универсальных магазинов
10 продавцов контрактных деталей
5 разборок BMW/VAG/European
5 кузовных поставщиков
5 агрегатных продавцов
5 автоэлектронщиков/блоков
5 логистических/доставочных контактов
```
