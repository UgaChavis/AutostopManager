# 10. Дорожная карта реализации

## Фаза 0. Настройка целей

Решить:

- какие марки обслуживаются чаще всего;
- какие категории деталей дают максимальную боль;
- какие поставщики уже есть у сервиса;
- кто будет подтверждать наличие;
- где будет храниться база.

## Фаза 1. MVP (Minimum Viable Product — минимально жизнеспособный продукт)

Срок: 1–2 недели разработки.

Функции:

- ручной ввод заявки;
- нормализация артикула;
- ручной ввод предложений;
- скоринг;
- отчет;
- журнал результата заказа.

Критерий успеха:

```text
Менеджер может сравнить 5–20 предложений и выбрать вариант за 5–10 минут.
```

## Фаза 2. Один B2B API

Функции:

- авторизация;
- поиск по артикулу;
- получение цены/остатка/срока;
- преобразование в Offer;
- обработка ошибок;
- кеширование.

Критерий успеха:

```text
По точному артикулу система возвращает предложения поставщика и корректно оценивает их.
```

## Фаза 3. VIN-каталог

Функции:

- поиск по VIN;
- получение OEM;
- получение замен и аналогов;
- проверка применяемости.

Критерий успеха:

```text
Система не проценивает рискованные позиции без проверки применяемости.
```

## Фаза 4. Локальный реестр продавцов Красноярска

Функции:

- импорт продавцов;
- категории;
- журнал звонков;
- внутренний рейтинг;
- подбор продавцов по категории детали.

Критерий успеха:

```text
Для срочной заявки система предлагает список продавцов, которым стоит звонить первыми.
```

## Фаза 5. Маркетплейсы в безопасном режиме

Функции:

- генератор запросов Авито/Дром/FarPost;
- ручной импорт объявления;
- оценка объявления;
- чек-лист звонка;
- сравнение б/у и нового варианта.

Критерий успеха:

```text
Менеджер быстрее находит б/у/контрактные детали и меньше ошибается по применяемости.
```

## Фаза 6. Логистика

Функции:

- расчет доставки;
- итоговая цена;
- учет задержек;
- сравнение локального и удаленного предложения.

Критерий успеха:

```text
Система выбирает не самую дешевую деталь, а лучшую по итоговой стоимости и сроку.
```

## Фаза 7. Самообучение на обратной связи

Функции:

- хранение результата заказа;
- обновление рейтинга продавца;
- обновление риска кросса;
- обнаружение проблемных брендов и поставщиков.

Критерий успеха:

```text
Через 100–300 заказов система заметно улучшает приоритеты источников и продавцов.
```

## Метрики

| Метрика | Как измерять |
|---|---|
| время поиска | от заявки до отчета |
| процент неподходящих деталей | не подошло / заказано |
| задержки | фактический срок - обещанный срок |
| доля подтвержденных наличий | подтверждено / рекомендовано |
| экономия | выбранный вариант против медианы |
| возвраты | возвраты / заказано |
| точность срочного поиска | получено сегодня/завтра / срочные заявки |
