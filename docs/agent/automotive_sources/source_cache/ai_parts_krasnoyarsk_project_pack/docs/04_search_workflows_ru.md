# 04. Рабочие сценарии поиска

## Сценарий 1. Новая деталь, срочно в Красноярске

1. Принять заявку.
2. Проверить VIN или минимальные признаки применяемости.
3. Найти OEM-номер и допустимые аналоги.
4. Запустить B2B API по OEM и кроссам.
5. Отфильтровать предложения с получением сегодня/завтра.
6. Проверить локальную базу продавцов.
7. Если API не дал результат, искать продавцов через 2ГИС/Яндекс Карты по профилю.
8. Позвонить лучшим продавцам.
9. Зафиксировать: наличие, срок резерва, цена, способ оплаты, возврат, имя менеджера.
10. Выдать рекомендацию.

### Правило

Если деталь нужна сегодня, цена получает меньший вес, чем подтвержденное наличие.

## Сценарий 2. Новая деталь под заказ по России

1. Получить точный OEM или надежный кросс.
2. Запросить B2B-поставщиков.
3. Рассчитать итоговую цену с доставкой.
4. Сравнить сроки.
5. Исключить предложения с подозрительно низкой ценой.
6. Проверить возвратность.
7. Выбрать 2–3 варианта: дешевый, быстрый, сбалансированный.

## Сценарий 3. Б/у или контрактная деталь

1. Получить маркировку старой детали или узла.
2. Составить список поисковых фраз.
3. Проверить Авито, Дром, FarPost вручную или через разрешенные инструменты.
4. Проверить разборки Красноярска и соседних регионов.
5. Запросить фото маркировки, креплений, состояния.
6. Для агрегатов запросить видео работы, гарантию, условия возврата.
7. Оценить продавца: профиль, отзывы, срок работы, повторяемость телефонов, адрес.
8. Сравнить с новым аналогом, если он существует.

## Сценарий 4. Кузовная деталь

1. Уточнить кузов, рестайлинг, сторону, комплектацию.
2. Уточнить цвет и требование к окраске.
3. Поискать OEM и аналоги.
4. Проверить б/у предложения с фото.
5. Попросить фото креплений, внутренней стороны, дефектов.
6. Добавить стоимость окраски, ремонта и доставки.
7. Не сравнивать только по цене: геометрия и крепления важнее.

## Сценарий 5. Электронный блок

1. Получить VIN.
2. Получить номер старого блока.
3. Снять фото всех наклеек.
4. Проверить аппаратную и программную совместимость.
5. Уточнить, нужен ли virgin, clone, coding, programming.
6. Не покупать блок без условия возврата, если совместимость не подтверждена.
7. В отчете указать дополнительные работы: кодирование, привязка, перенос EEPROM/Flash, адаптации.

## Сценарий 6. Редкая деталь

1. Расширить географию: Красноярск → Новосибирск → Иркутск → Екатеринбург → Москва/Санкт-Петербург → Владивосток.
2. Искать не только OEM, но и замененные номера.
3. Проверить англоязычные и японские формулировки, если деталь контрактная.
4. Сформировать лист ожидания у разборок.
5. Зафиксировать рыночную медиану и допустимый бюджет.

## Сценарий 7. Нет точного номера

1. Не проценивать как финальный заказ.
2. Составить список уточнений.
3. Выдать менеджеру шаблон запроса клиенту.
4. Если ремонт уже идет, попросить фото снятой детали.
5. После получения данных повторить идентификацию.
