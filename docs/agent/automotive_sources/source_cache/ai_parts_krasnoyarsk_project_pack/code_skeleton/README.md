# Кодовый скелет

Файлы здесь не являются готовой промышленной системой, но задают основу:

- `models.py` — модели заявки, предложения и продавца;
- `normalization.py` — нормализация артикулов и брендов;
- `scoring.py` — расчет рейтинга предложений;
- `connectors_base.py` — интерфейс API-коннектора;
- `manual_marketplace.py` — безопасная генерация запросов для Авито/Дром/FarPost;
- `reporting.py` — отчет менеджеру;
- `example_run.py` — запуск на синтетических данных.

Для проверки:

```bash
cd code_skeleton
python example_run.py
```

Реальные API-ключи не добавлять в код. Использовать переменные окружения.
