# Схемы данных

Эта папка задает контракты данных для проекта.

- `part_request.schema.json` — заявка на запчасть.
- `offer.schema.json` — предложение поставщика/продавца.
- `seller.schema.json` — локальный или внешний продавец.
- `search_report.schema.json` — отчет для менеджера.
- `feedback.schema.json` — обратная связь после заказа.

Codex должен использовать эти схемы как основу моделей Python и валидации входных/выходных данных.
