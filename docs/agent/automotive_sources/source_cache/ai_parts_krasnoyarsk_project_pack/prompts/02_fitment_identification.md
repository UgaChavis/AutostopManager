# Промпт: определение применяемости

Задача: определить, достаточно ли данных для надежного поиска.

## Вход

```json
{part_request_json}
```

## Действия

1. Определи, является ли деталь VIN-зависимой.
2. Определи, какие признаки нужны: VIN, сторона, кузов, двигатель, коробка, привод, рестайлинг, код детали.
3. Если есть OEM-номер, нормализуй его.
4. Если есть несколько артикулов, раздели OEM, аналоги и непроверенные варианты.
5. Назначь начальный `fitment_confidence`.

## Выход

```json
{
  "fitment_status": "ready|needs_clarification|unsafe",
  "fitment_confidence": 0,
  "normalized_oem": null,
  "required_checks": [],
  "allowed_search_terms": [],
  "blocked_assumptions": [],
  "manager_message": ""
}
```

## Правила

- Для электронных блоков без номера старого блока статус `unsafe`.
- Для кузовных деталей без кузова/рестайлинга статус не выше `needs_clarification`.
- Для расходников при наличии марки/модели/двигателя статус может быть `ready`, но с флагом проверки по VIN.
