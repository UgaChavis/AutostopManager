Ты — инженерный агент Codex, который должен расширить проект автосервиса по поиску автозапчастей в Красноярске и России.

Задача: построить систему поддержки менеджера автосервиса для поиска, проверки и выбора автозапчастей.

Контекст:
- Сервис работает в Красноярске.
- Нужны новые, б/у и контрактные детали.
- Источники: B2B API поставщиков, VIN-каталоги, 2ГИС, Яндекс Карты, Авито, Дром, FarPost, локальные продавцы, логистические API.
- Авито/Дром/FarPost использовать только в разрешенном режиме: генерация запросов, ручной ввод найденных объявлений или официальные API при наличии доступа. Не писать скрытые парсеры, не обходить CAPTCHA, не нарушать rate-limit и правила площадок.

Что нужно реализовать:
1. Прочитай все файлы архива.
2. Построй модульную архитектуру:
   - intake: прием заявки;
   - identity: нормализация автомобиля и детали;
   - catalog: OEM/кроссы/VIN;
   - sources: коннекторы источников;
   - scoring: оценка предложений;
   - reporting: отчет для менеджера;
   - feedback: результат заказа и обучение рейтингов.
3. Используй схемы из папки schemas как контракт данных.
4. Используй configs/source_registry.yaml как реестр источников.
5. Сначала реализуй offline MVP на синтетических данных из data/sample_offers_synthetic.jsonl.
6. Затем подготовь интерфейсы для реальных API, но не добавляй учетные данные в код.
7. Все секреты должны читаться из переменных окружения.
8. Логируй источник, время, параметры запроса и свежесть данных, но не храни лишние персональные данные.
9. Для каждого предложения рассчитывай:
   - fitment_score;
   - availability_score;
   - delivery_score;
   - price_score;
   - seller_score;
   - warranty_score;
   - risk_penalty;
   - final_score;
   - expected_total_cost.
10. Отчет должен показывать три варианта: быстрый, дешевый, сбалансированный.

Ключевой принцип: правильная применяемость и подтвержденное наличие важнее минимальной цены.

Ограничения безопасности и законности:
- Не реализовывать обход защиты сайтов.
- Не реализовывать массовый несанкционированный сбор объявлений.
- Не использовать неофициальные endpoints без разрешения.
- Не выдавать неподтвержденное наличие как факт.
- Не делать VIN-зависимый подбор по догадке.
