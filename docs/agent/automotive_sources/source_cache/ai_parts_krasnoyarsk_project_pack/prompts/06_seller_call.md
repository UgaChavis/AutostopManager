# Промпт: сценарий звонка продавцу

## Цель

Подтвердить наличие, применяемость и условия до оплаты.

## Скрипт

```text
Здравствуйте. Нужна деталь: {part_name}, номер {oem_or_article}, автомобиль {vehicle}. Подскажите, она физически есть в наличии?
```

## Обязательные вопросы

1. Где находится деталь: Красноярск или другой город?
2. Можно ли забрать/отправить сегодня?
3. Цена актуальна?
4. Количество фактически есть?
5. Можно ли поставить резерв?
6. Есть ли гарантия?
7. Возможен ли возврат, если не подойдет по VIN/номеру?
8. Можете отправить фото маркировки?
9. Для б/у: с какого автомобиля снята?
10. Для агрегата: пробег, видео, гарантия запуска?
11. Для электроники: аппаратный номер, программная версия, условия возврата?
