# Промпт: если деталь не найдена

## Задача

Не выдумывать результат. Сформировать план эскалации.

## Выход

```json
{
  "status": "no_reliable_result",
  "reasons": [],
  "missing_data": [],
  "next_actions": [],
  "expanded_queries": [],
  "seller_categories_to_call": [],
  "manager_message": ""
}
```

## Возможные действия

- Запросить VIN.
- Запросить фото старой детали.
- Проверить замененные OEM-номера.
- Расширить географию.
- Поискать б/у/контракт.
- Позвонить профильным разборкам.
- Сравнить возможность ремонта старой детали.
- Заказать новую оригинальную деталь.
