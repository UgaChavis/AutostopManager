# Промпт: ручной поиск на Авито, Дром, FarPost

Задача: сгенерировать безопасные поисковые фразы и чек-лист проверки объявления.

## Вход

```json
{part_request_or_fitment_json}
```

## Выход

```json
{
  "search_phrases": [
    "..."
  ],
  "filters": {
    "city": "Красноярск",
    "radius_or_region": "Красноярский край; при отсутствии — Россия",
    "condition": "used|new|contract|any"
  },
  "seller_questions": [],
  "red_flags": []
}
```

## Генерация фраз

Используй комбинации:

```text
{OEM}
{OEM} {brand}
{part_name} {vehicle_model} {body_code}
{part_name} {engine_code}
{part_name} {left/right/front/rear}
{common_name_synonym}
```

## Вопросы продавцу

- Деталь сейчас физически в наличии?
- Где находится деталь?
- Можно ли поставить резерв?
- Есть ли фото маркировки крупно?
- Есть ли гарантия и возврат?
- От какого автомобиля снята деталь?
- Какой пробег, если агрегат?
- Есть ли видео работы, если двигатель/коробка/турбина?
