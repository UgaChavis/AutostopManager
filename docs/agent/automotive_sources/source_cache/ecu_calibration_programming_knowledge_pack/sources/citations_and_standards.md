# Каталог публичных источников и стандартов

Материал не включает копии закрытых заводских руководств или платных стандартов. Этот файл указывает публичные страницы, по которым можно проверить назначение стандартов и официальных порталов.

## ASAM MCD-2 MC (ASAP2/A2L)

URL: https://www.asam.net/standards/detail/mcd-2-mc/

Назначение: Описание формата A2L для внутренних переменных ECU, измерений и калибровок.

Доступ: Публичная обзорная страница; полная спецификация может иметь лицензионные условия.

## ASAM MCD-2 D (ODX)

URL: https://www.asam.net/standards/detail/mcd-2-d/

Назначение: Описание ODX как стандарта обмена диагностической информацией ECU.

Доступ: Публичная обзорная страница; полная спецификация может иметь лицензионные условия.

## ASAM MDF

URL: https://www.asam.net/standards/detail/mdf/

Назначение: Описание MDF как бинарного формата измерительных данных.

Доступ: Публичная обзорная страница; часть документов доступна по условиям ASAM.

## ASAM CDF

URL: https://www.asam.net/standards/detail/cdf/

Назначение: Описание CDF как формата хранения значений калибровочных параметров и метаданных.

Доступ: Публичная обзорная страница.

## ISO 14229-1:2020 Unified Diagnostic Services

URL: https://www.iso.org/standard/72439.html

Назначение: Описание UDS как диагностических сервисов, позволяющих тестеру управлять диагностическими функциями ECU.

Доступ: Публичная аннотация; полный стандарт платный.

## ISO 15765-2 Diagnostic communication over CAN (DoCAN)

URL: https://www.iso.org/standard/94385.html

Назначение: Описание транспортного и сетевого уровня для диагностических сообщений поверх CAN.

Доступ: Публичная аннотация; полный стандарт платный.

## ISO 13400-2 Diagnostics over Internet Protocol (DoIP)

URL: https://www.iso.org/standard/74785.html

Назначение: Описание диагностической коммуникации по IP/TCP/UDP между тестером и сервером DoIP автомобиля.

Доступ: Публичная аннотация; полный стандарт платный.

## SAE J2534 Pass-Thru Vehicle Programming

URL: https://www.sae.org/standards/j2534-1_5_00-recommended-practice-pass-thru-vehicle-programming

Назначение: Рекомендуемая практика совместимости ПО OEM с интерфейсами pass-thru.

Доступ: Публичная аннотация; полный стандарт платный.

## AUTOSAR Classic Platform

URL: https://www.autosar.org/standards/classic-platform

Назначение: Слои AUTOSAR Classic: Application, RTE, BSW для микроконтроллерных ECU.

Доступ: Публичная страница стандарта.

## BMW Aftersales Online System

URL: https://aos.bmwgroup.com/

Назначение: Официальный портал BMW Group для независимых мастерских, выполняющих ремонт и обслуживание.

Доступ: Доступ по условиям BMW Group.

## BMW AOS price list

Назначение: Указывает доступ к оригинальным техническим документам BMW: листы инспекции, ремонтные инструкции, электросхемы и др.

Доступ: Публичная страница с условиями доступа.

## EPA - Tampering and Aftermarket Defeat Devices

Назначение: Позиция EPA: установка defeat device и tampering экологических систем запрещены и влекут санкции.

Доступ: Публичная страница.

## CARB - Defeat devices warning
