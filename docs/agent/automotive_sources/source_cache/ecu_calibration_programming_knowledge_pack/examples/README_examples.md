# Синтетические учебные примеры файлов

Эти файлы не относятся к реальному автомобилю, не пригодны для записи в ECU и созданы только для обучения структуре форматов.

- toy_project_a2l.a2l - фрагмент A2L.
- toy_dcm_values.dcm - фрагмент DCM.
- toy_odx_snippet.xml - упрощенный фрагмент ODX.
- toy_intel_hex.hex - учебный Intel HEX.
- toy_motorola_srecord.s19 - учебный S-record.
- toy_calibration_metadata.json - метаданные учебной калибровки.
- toy_log_metadata_mdf.json - учебное описание измерительного лога.
