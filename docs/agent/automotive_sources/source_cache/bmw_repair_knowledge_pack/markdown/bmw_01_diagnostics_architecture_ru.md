**Кратко:** Справочник по ISTA, AIR, AOS, структуре диагностики BMW, типовым электронным блокам и шинам данных.

Дата сборки: 2026-05-03T10:32:46Z

## 1. Официальная диагностическая среда BMW

BMW использует VIN (Vehicle Identification Number — идентификационный номер автомобиля), модельный код, дату производства, комплектацию и уровень интеграции I-level (Integration Level — уровень программной интеграции) для выбора корректных ремонтных данных. Один и тот же коммерческий индекс, например BMW 320i или X5, может иметь разные блоки управления, проводку, двигатель, коробку передач и кампании в зависимости от VIN.

| Платформа | Расшифровка | Роль в ремонте |
| --- | --- | --- |
| AOS | Aftersales Online System — послепродажная онлайн-система BMW | Портал для независимых мастерских. Содержит доступ к ISTA, AIR и другим приложениям при наличии подписки. |
| ISTA | Integrated Service Technical Application — интегрированное сервисно-техническое приложение | Диагностика, планы проверки, программирование, ремонтные инструкции, технические данные и схемы. В документации BMW указано, что ISTA следует использовать для программирования F-серии, G-серии и более новых автомобилей. |
| ISTA/P | Integrated Service Technical Application / Programming — приложение программирования | Программирование старых E-серий BMW и R-серий MINI. |
| AIR | Aftersales Information Research — послепродажная информационная система | Информация о деталях, нормах времени, технических спецификациях и поиске по шасси. |
| TIS | Technical Information System — техническая информационная система | Технические бюллетени и сервисная информация. Ремонтные инструкции выбираются через AIR или ISTA, а не обычным поиском TIS. |
| P-code lookup | Powertrain code lookup — поиск кодов силового агрегата | Расшифровка стандартных OBD II (On-Board Diagnostics II — бортовая диагностика второго поколения) кодов. |

## 2. Минимальная карточка автомобиля для точной диагностики

- 17-значный VIN (Vehicle Identification Number — идентификационный номер автомобиля).
- Кузовной код: E46, E90, F30, G20, G05 и т. п.
- Двигатель: например M54, N52, N54, N55, B48, B58, N47, N57, B47, N63.
- Коробка передач: механическая, ZF 5HP/6HP/8HP, GM 5L40/6L45, DCT (Dual-Clutch Transmission — коробка передач с двумя сцеплениями), гибридная трансмиссия.
- Привод: задний привод, xDrive (полный привод BMW), гибрид или электрический привод.
- Уровень интеграции I-level, версия программного обеспечения и список открытых технических кампаний.
- Полный список ошибок со статусом: active/current (активная), stored (сохраненная), shadow (теневая), pending (ожидающая подтверждения), confirmed (подтвержденная).
- Freeze frame (зафиксированный кадр параметров) и измеряемые значения в момент появления ошибки.

## 5. Диагностическая логика BMW

- Сначала отделяют неисправность системы от следствия: низкое напряжение, плохая масса, вода в разъемах и ошибки связи могут создать десятки вторичных кодов.
- Для программных ошибок важны I-level и сервисные бюллетени. В публичном бюллетене BMW по коду 8013FE в IHKA указано, что замена деталей не является средством ремонта, если причина — программное обеспечение.
- Для ошибок связи важны топология шины, питание блоков, массы, пробуждение/сон автомобиля и наличие блоков после дооснащения.
- Для силового агрегата нужно связывать код с измеряемыми значениями: давление наддува, коррекции топлива, давление топлива, температура, частота вращения, нагрузка, состояние регуляторов.
- После программирования или кодирования в BMW возможны последующие действия: удаление памяти неисправностей, калибровки и проверочные поездки. Конкретный набор действий задается ISTA.
