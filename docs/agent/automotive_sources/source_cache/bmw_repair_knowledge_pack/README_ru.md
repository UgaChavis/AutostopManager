# BMW repair knowledge pack

Архив содержит справочные материалы по ремонту и диагностике BMW в компактном
индексируемом виде: Markdown и JSONL (JSON Lines — построчный JSON).

Состав:

- `markdown/` — машиночитаемые справочники по диагностике, кодам
  неисправностей, двигателям, коробкам передач, xDrive, шасси, кузовной
  электронике, высоковольтным системам и жидкостям.
- `data/` — JSONL-индексы: кузовные коды, двигатели, коробки, электронные
  блоки, публичные примеры BMW fault memory, симптомы и жидкости.
- `manifest.json` — компактный список активных файлов.

Сгенерированные PDF, CSV, HTML, plaintext-дубли, общий OBD-глоссарий и
публичный source snapshot удалены: активная база знаний использует только
Markdown/JSONL, которые нужны маршрутизации.

Материалы являются оригинальными справочными конспектами и не включают закрытые руководства BMW ISTA (Integrated Service Technical Application — интегрированное сервисно-техническое приложение), AIR (Aftersales Information Research — послепродажная информационная система) или коммерческие PDF производителей. Для точных моментов затяжки, объемов, кодирования, программирования и кампаний требуется VIN (Vehicle Identification Number — идентификационный номер автомобиля) и официальный источник.
