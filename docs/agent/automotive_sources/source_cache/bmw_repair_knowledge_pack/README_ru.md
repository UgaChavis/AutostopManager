# BMW repair knowledge pack

Архив содержит справочные материалы по ремонту и диагностике BMW в виде PDF (Portable Document Format — переносимый формат документа), Markdown, CSV (Comma-Separated Values — значения, разделенные запятыми) и JSONL (JSON Lines — построчный JSON).

Состав:

- `pdf/` — 8 PDF-справочников по диагностике, кодам неисправностей, двигателям, коробкам передач, xDrive, шасси, кузовной электронике, высоковольтным системам и жидкостям.
- `markdown/` — те же материалы в машиночитаемом текстовом формате.
- `data/` — таблицы и JSONL-индексы: кузовные коды, двигатели, коробки, электронные блоки, OBD II (On-Board Diagnostics II — бортовая диагностика второго поколения), публичные примеры BMW fault memory, симптомы, жидкости и источники.
- `html/index.html` — локальная страница-оглавление.

Материалы являются оригинальными справочными конспектами и не включают закрытые руководства BMW ISTA (Integrated Service Technical Application — интегрированное сервисно-техническое приложение), AIR (Aftersales Information Research — послепродажная информационная система) или коммерческие PDF производителей. Для точных моментов затяжки, объемов, кодирования, программирования и кампаний требуется VIN (Vehicle Identification Number — идентификационный номер автомобиля) и официальный источник.
