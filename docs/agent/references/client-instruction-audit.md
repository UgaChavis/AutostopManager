## Цепочка чтения

Входящее B1 → событие B4 → `$manage-owner-telegram` → актуальные AGENTS/B2 → точный адресат и подтверждённая роль → полный клиентский скилл для `client` либо поручение владельца для `owner` → необходимые технические модули.

`telegram_wake.py` задаёт cwd `/opt/AutostopManager`. Установленный prompt ведёт к текущим AGENTS/B2 этой директории и требует заменить устаревшие правила истории актуальными. Поэтому изменение рабочего маршрута инструкций не требует изменения wake-кода. Наличие старых документов в immutable snapshots отдельно не доказывает, что агент читает их вместо checkout.
