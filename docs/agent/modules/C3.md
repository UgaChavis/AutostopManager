# C3 — CRM

CRM хранит клиентов, автомобили, обращения и заказ-наряды AutoStop. Текущие данные и история остаются в CRM; доступ для Codex — через [C2](C2.md).

## Вложенные возможности

- [C4 — Клиенты и телефоны](C4.md): профили, контакты и связанные обращения. (Используй для работы с клиентом.)
- [C5 — Автомобили](C5.md): паспорт автомобиля и связь с клиентом и карточкой. (Используй для уточнения машины.)
- [C6 — Карточки ремонта](C6.md): запрос, договорённости, состояние и следующий шаг. (Используй для ведения кейса.)
- [C7 — Заказ-наряды](C7.md): работы, материалы, расчёты и документы ремонта. (Используй для оформления ремонта.)

## Работа с данными

Найди нужные записи и прочитай их связи; продолжай существующий кейс без дубликата. Меняй только необходимые поля, сохраняй историю и проверяй результат. Выбирай команды и порядок по задаче и актуальной схеме C2.

Клиентское поведение и момент оформления — в [клиентском скилле](../../../.agents/skills/manage-autostop-client/SKILL.md); технические операции Store — в [F2](F2.md), документы и почта — в [справочнике](../references/crm-mail.md).
