# B4 — Запуск по событию

B4 передаёт текущее входящее событие рабочего Telegram агенту Codex в существующем видимом чате, когда включён рабочий режим. Это запуск работы по событию; читать диалог и отвечать агент может через B1 по [Telegram skill](../../../.agents/skills/manage-owner-telegram/SKILL.md).

## ОБРАБОТКА

Получив событие, определи его актуальный адресат через `monitor-target`, прочитай нужный контекст и выполни задачу. Старые ссылки на события не заменяй похожими адресатами. После результата заверши ход; событие и клиентская сделка имеют отдельное состояние.

## СОСТОЯНИЕ

- `telegram_wake status` — доступность Codex, включение запуска и состояние очереди.
- `monitor-status`, `monitor-events` — техническое состояние bridge без чтения сообщений.
- `telegram_wake pause`, `setup`, `probe` — служебные изменения режима или задачи; выбирай только для соответствующей порученной технической работы.

Точные команды смотри через текущий `--help` и [операционную инструкцию](../references/telegram-runtime.md). При неизвестном результате запуска сначала проверь текущий чат и событие; не воспроизводи его автоматически.
