# E5 — Найти оригинальный номер

E5 помогает найти OEM по автомобилю и запросу на деталь. Выбирай нужные инструменты через D1 в подходящем порядке.

## ПОИСК

- `lookup_original_parts` — план каталожной проверки, кандидаты и недостающий контекст.
- `partsapi_catalog_lookup` — конкретная операция доступного каталога.
- `plan_oem_parts_providers` — выбор источника и маршрута.
- `resolve_vin_oem_parts` — составное исследование по одному каталожному маршруту, если оно подходит задаче.

Учитывай название детали, сторону, положение, известный старый номер и характеристики автомобиля. Сверяй кандидат с каталожным источником и заменами номера. Результат поиска не повышает кандидат до подтверждённого OEM автоматически.

Подробнее: [E1](E1.md), [PartsAPI](../references/partsapi.md). Для публичной сверки используй [E7](E7.md).
