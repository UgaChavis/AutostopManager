# K1 — Сайт автосервиса

Публичный сайт [autostop24.ru](https://autostop24.ru/) представляет автосервис AutoStop: услуги, плановое обслуживание, контакты и сведения о приватности. Это отдельный проект на MNG1, исходники — `/opt/autostop-website`, опубликованные файлы — физическая цель `/var/www/autostop24/current`.

Содержание, дизайн и маркетинговые обещания меняй в пределах поручения владельца. Перед работой прочитай README и профильные документы самого сайта; проверь HEAD, diff, происхождение выбранной версии и штатную publish receipt. Локальная ветка или похожее имя release не подтверждают утверждение или публикацию версии.

## Связи

- [A2 — Codex](../../../AGENTS.md) выполняет поручение; [M2](M2.md) обслуживает код и выпуск по [порядку сайта](../references/website-runtime.md).
- [B2 — рабочий Telegram](B2.md) обрабатывает обращения после перехода посетителя по обычной контактной ссылке. Сайт не создаёт клиентскую карточку и не отправляет сообщение от имени посетителя.
- [C3 — CRM](C3.md) хранит рабочие записи; [F2 — Store](F2.md) — отдельный магазин запчастей. Публичная страница сайта не подтверждает склад, цену конкретной детали или запись на ремонт.
- [H1 — аналитика](H1.md) используется по доступным подключённым возможностям. Фактический сбор аналитики сайта, счётчик и события определяются его исходниками и опубликованной версией; доступ к рекламному кабинету проверяется отдельно.

## Обслуживание и проверка

Сайт статический: `public/`, локальные assets и выделенный Nginx virtual host. Собственного MCP, базы данных и прикладной службы у K1 нет. Не добавляй ему вымышленные API или действия конструктора.

Правку проверь целевыми тестами сайта и сверкой точного `public/`. Подготовка release, активация и rollback — разные действия; выпуск выполняй только в разрешённом объёме, сохраняя предыдущую цель и квитанцию. После активации проверь HTTPS, канонические redirect с query string, затронутые страницы/assets, robots/sitemap и закрытость внутренних путей. Проверка ссылок не отправляет сообщения и не создаёт бизнес-записи.

Инструкции K1 выпускаются с Manager, а содержимое сайта — своим механизмом. Оба результата подтверждай отдельными ревизиями и проверками: [website-runtime.md](../references/website-runtime.md).
