# E10 — Б/у, контрактные и восстановленные детали

Объявления и sourcing leads
Родитель: [E1](E1.md). Устойчивый ключ: `used_parts_offers`.

## Входы

Обезличенный запрос, регион, состояние/комплектность; listing точной детали.
