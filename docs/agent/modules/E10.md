# E10 — Авито / ReefAPI

E10 ищет объявления Авито через ReefAPI. Инструменты доступны через D1; доступность текущего поиска оценивай по результату вызова.

## ИНСТРУМЕНТЫ

- `avito_search_listings` — поиск по детали и региону.
- `avito_read_listing` — подробности выбранного объявления.
- `assess_avito_price_sample` — оценка уже собранной выборки по точному артикулу, без нового обращения к источнику.

Ищи по артикулу и названию детали, без полного VIN, контактов и секретов. Начинай с нужного региона, расширяй поиск, когда доставка подходит задаче. Сверяй цену, состояние, город, ссылку и время наблюдения. Выборочная медиана появляется при достаточном числе разных объявлений в одном сегменте.

Поиск читает одну страницу: `page` — целое 1–30, `limit` — число принятых уникальных результатов 1–50. Цены задавай целыми рублями, флаги — JSON boolean. Для чтения подходит числовой ID или ссылка Авито. `dry_run=true` проверяет запрос без обращения к поставщику.

Различай отсутствие объявления, исчерпание кредитов, ограничение частоты, таймаут и ошибку формата поставщика. Отмена ожидания не подтверждает остановку уже отправленного запроса; автоматического повтора нет. Не запускай повтор платного чтения, пока результат предыдущего остаётся неопределённым.

Объявление — зацепка для дальнейшей проверки. Наличие, применимость и цена продавца требуют отдельного подтверждения. Подробнее: [источники объявлений](../references/market-listings.md).
