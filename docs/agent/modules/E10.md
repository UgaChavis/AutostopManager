# E10 — Б/у, контрактные и восстановленные детали

Объявления и sourcing leads
Родитель: [E1](E1.md). Устойчивый ключ: `used_parts_offers`.

## Входы

Обезличенный запрос, регион, состояние/комплектность; listing точной детали.

## Достаточность и границы

- Queued task не найдённая деталь; б/у, reman и новая — разные сегменты.

## Следующий выбор

После запуска Drom сохрани исходные `task_id`/`uid`. Для обычного ожидания `queued/running` выполняй не более двух чтений `drom_get_parts_search` в текущем клиентском ходе и только в пределах оставшегося общего бюджета задания. Если результат не готов в этих пределах, дай полезный предварительный ответ, используй доступную альтернативу либо согласованную передачу человеку по клиентскому скиллу.

Задержка не разрешает новый start. После завершения хода не создавай цели, таймеры или polling. Лимит обычного ожидания не отменяет сверку неизвестного исхода исходного действия и не разрешает обходить блокировку новых отправок. Применимость — [E6](E6.md), оценка уже собранных объявлений — [E11](E11.md).
