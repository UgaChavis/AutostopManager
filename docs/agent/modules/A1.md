# A1 — Навигация AutoStop Manager

Выбери модуль по задаче, прочитай актуальные правила; используй готовые данные и переходи дальше ради недостающего результата/проверки. Полномочия — [AGENTS.md](../../../AGENTS.md). Для рабочего клиента обязателен полный скилл по [B2](B2.md).

Live-операции: физический installed snapshot и REVISION; разработка: выбранный checkout/worktree, HEAD и diff. Порядок корней — [A3](A3.md), текущие tool schemas и endpoint/client declarations — [D1](D1.md).
