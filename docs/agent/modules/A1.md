# A1 — Навигация AutoStop Manager

Выбери модуль по задаче и прочитай его актуальную инструкцию. Вложенные возможности описаны у родителей. Общие полномочия — в AGENTS.md; клиентское поведение — только в [клиентском скилле](../../../.agents/skills/manage-autostop-client/SKILL.md), выбранном через [B2](B2.md). Модули содержат технические операции, источники, ценовую политику и проверки; остальные навыки дают профильные инструкции или навигацию. Схемы инструментов проверяй в текущем сеансе.

Текущая карта модулей и связей — [конструктор менеджера](https://crm.autostopcrm.ru/manager-structure).

## Роли

- [M1 — Кабинет директора](M1.md): цели, координация и приёмка. Читай при поручении работать директором.
- [M2 — Кабинет технического инженера](M2.md): диагностика, восстановление, оптимизация и журналы. Читай при техническом поручении; M2 подчинён M1.
- [A2 — Агент Codex](../../../AGENTS.md): общие правила и полномочия.

## Инфраструктура

MNG1 — Manager, CRM, Store и их прикладные службы.
MNG2 — служебный VPN;
fst.kz — публичный VPN.

Сначала установи точный контур; техническое поручение по прикладному проекту не расширяет работу на VPN и управляемые ПК. Разделение хостов, ревизии и проверки — [операции хостов](../references/host-operations.md).
