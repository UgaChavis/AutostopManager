# A1 — Навигация AutoStop Manager

Выбери нужный модуль по задаче и прочитай его инструкцию. Вложенные возможности перечислены в инструкциях родителей; навыки и дополнительные материалы доступны через A4 и A5.

## КАТАЛОГИ ИНСТРУКЦИЙ

- **A4 — Каталог навыков:** актуальные навыки Manager, Codex и плагинов. [Открыть A4](A4.md) (Используй, когда нужно выбрать навык и найти его SKILL.md.)
- **A5 — Полный указатель инструкций:** полный указатель инструкций и справочников. [Открыть A5](A5.md) (Обращайся, когда неясно, где описана нужная возможность, или обычного списка модулей недостаточно.)

Каталоги A4 и A5 перечисляют действующие инструкции и навыки. Обновляй их при изменении документов или состава плагинов.

## РЕСУРСЫ

- **B2 — Рабочий Telegram-аккаунт:** рабочие диалоги с клиентами через B1; входящие могут запускать Codex. [Подробнее о B2](B2.md) (Используй для рабочих диалогов с клиентами и ответов по текущему обращению.)
- **B3 — Личный Telegram-аккаунт:** личная переписка через B1, без событийного запуска Codex. [Подробнее о B3](B3.md) (Используй, когда задача касается личного аккаунта или его диалогов.)
- **C3 — CRM:** клиенты, автомобили, ремонты и документы; доступ через C2. [Подробнее о C3](C3.md) (Используй для поиска данных клиента и автомобиля, записи на ремонт, ведения карточки ремонта, заказ-наряда и расчётов.)
- **D3 — SQLite + файлы:** файлы знаний и служебное состояние Manager. [Подробнее о D3](D3.md) (Используй, когда нужны сохранённые знания Manager.)
- **E2 — vPIC / PartsAPI:** расшифровка VIN и каталожные сведения. [Подробнее о E2](E2.md) (Используй, когда нужны данные этих источников.)
- **E3 — Каталоги и поставщики:** каталоги и предложения поставщиков. [Подробнее о E3](E3.md) (Используй для проверки вариантов деталей и условий поставки.)
- **E10 — Авито / ReefAPI:** объявления запчастей через ReefAPI. [Подробнее о E10](E10.md) (Используй для поиска предложений по артикулу, если источник доступен.)
- **E11 — Drom / Webbee:** объявления Drom через Webbee при доступном источнике. [Подробнее о E11](E11.md) (Используй для поиска объявлений после подтверждения доступности источника.)
- **F2 — Магазин запчастей:** каталог, склад, проценки и заказы; доступ через F1. [Подробнее о F2](F2.md) (Используй для проверки запчастей и наличия, подготовки предложений и работы с заказами.)
- **H2 — Instagram AutoStop:** рабочие публикации и комментарии; доступ через H1. [Подробнее о H2](H2.md) (Используй для чтения аккаунта, публикаций и работы с комментариями по задаче.)

## ИНСТРУМЕНТЫ

- **A3 — Терминал / CLI:** локальные команды, файлы и вывод терминала. [Подробнее о A3](A3.md) (Используй для работы с файлами, командами и локальными службами проекта.)
- **B1 — Telegram-мост:** чтение, отправка и медиа Telegram через выбранный аккаунт. [Подробнее о B1](B1.md) (Используй для работы с Telegram-диалогами и сообщениями по задаче пользователя.)
- **C2 — CRM MCP-коннектор:** инструменты доступа к текущей CRM. [Подробнее о C2](C2.md) (Используй для чтения и изменения данных CRM по запросу пользователя.)
- **D1 — AutoStop Manager MCP:** MCP-инструменты подбора, Store, публичного веба и автоматизаций. [Подробнее о D1](D1.md) (Используй, когда для задачи нужны возможности этих модулей.)
- **E8 — Веб-шлюз:** поиск и чтение публичных страниц. [Подробнее о E8](E8.md) (Используй, когда нужны открытые веб-источники по детали или её цене.)
- **F1 — Адаптер Store:** инструменты доступа Manager к API Store. [Подробнее о F1](F1.md) (Используй для чтения данных магазина и выполнения доступных действий в нём.)
- **H1 — Windsor.ai:** инструменты рабочего Instagram через плагин Windsor.ai. [Подробнее о H1](H1.md) (Используй для работы с Instagram через доступный коннектор.)
- **J1 — Интернет-исследования:** сбор публичных источников и отчёт по исследованию. [Подробнее о J1](J1.md) (Используй, когда нужны актуальные сведения и проверка источников в открытом интернете.)

- **G1 — Центр автоматизаций:** периодические задания, таймеры и готовность. [Подробнее о G1](G1.md) (Используй для проверки и настройки автоматических заданий.)
