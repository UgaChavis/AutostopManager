# J1 — Интернет-исследования

J1 помогает найти публичные источники и проверить факты. Устойчивый ключ `public_research`.
Выбери способ исследования по вопросу, известным данным и нужной глубине.

## Публичный поиск

1. Сформулируй вопрос и ограничения. Уточняй только то, от чего меняется результат.
2. Используй встроенный веб-поиск Codex (GPT Search), если он доступен в текущем ходе. Передавай обезличенные признаки, например модель, год, код узла, DTC или артикул. Исключи VIN, контакты, данные CRM и Telegram, секреты из запроса и URL.
3. Для короткой проверки прочитай нужную страницу через `fetch_page_excerpt` или `fetch_page_browser`. Если нужен сбор нескольких документов, передай 2–4 подходящих публичных URL в `j1_research_sources` вместе с обезличенным `automotive_context`, затем прочитай статус, материалы и отчёт. Для недоступного встроенного поиска используй `search_web_multi` или `j1_research_start`, когда такой маршрут доступен для задачи. Публичные каталожные операции выбирай по [E4](E4.md).
4. Известный DTC ищи через `j1_research_results(query_mode=dtc)`, артикул — через `query_mode=part_number`. Уточняй поиск по конкретным пробелам и противоречиям в пределах бюджета. В ответе укажи прямую ссылку и страницу или выдержку для важного факта. Проверь цитаты применимости и точное совпадение кода. Сохраняй явные исключения, конфликты и неизвестные условия. При недоступности маршрутов дай результат в подтверждённом объёме и укажи пробелы.

Ссылка и поисковая выдержка служат для обнаружения документа. При отказе доступа проверь другой независимый разрешённый источник. Elcats/Japancats запрещают автоматическое чтение каталожных страниц по зафиксированной robots-политике. Не используй альтернативный reader, поиск, proxy или login для обхода отказа. [Границы публичного чтения](../references/web-research.md) и [матрица каталогов](../references/elcats.md).

Для применимости используй [E6](E6.md), для рынка [E11](E11.md), для технических данных [E14](E14.md). J1 возвращает материалы и основания. Подтверждение диагноза, применимости, наличия и условия сделки проверяй по соответствующему процессу.

## Исследование по VIN

По поручению исследовать конкретный VIN используй `j1_research_vin`. Для старта достаточно одного номера. Режим работает отдельно от E2/E4 и decoder API. Полный VIN допускается в одной временной VIN-job с исходным номером, фиксированными получателями, бюджетом и сроком. Публичный поиск Codex, обычные инструменты J1 и URLs браузера с VIN не входят в этот маршрут.

Сначала проверь статус и прочитай документы порциями. Текущий агент записывает подтверждённые цитатами утверждения через `j1_research_record_facts` и при необходимости добавляет уточнения в том же бюджете. `collection_status` отражает сбор, `analysis_status` отражает анализ. Заверши анализ для версионированного отчёта. Семейные данные, выводы, противоречия и неизвестное проверяй в их области. Один найденный VIN не доказывает заводскую комплектацию.

VIN-режим по умолчанию выключен. Контракт, доступ, большие PDF и временная OCR-очередь выбранной страницы описаны в [справочнике VIN](../references/j1-vin-research.md). Сведения о побочных эффектах чтения, временном состоянии, сроках и лимитах — в [справочнике J1](../references/web-research.md).
