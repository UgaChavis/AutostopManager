# C5 — Автомобили

C5 — автомобили клиентов в CRM: марка, модель, VIN или номер кузова, госномер, год, пробег и известные технические характеристики. Карточка обращения может ссылаться на автомобиль клиента и содержать свой профиль машины.

## ПОИСК И ЧТЕНИЕ

Через `agent_search` и `agent_entity_context` найди автомобиль, его владельца и связанную карточку. Сверяй идентификаторы и связи, чтобы продолжить работу с нужной машиной.

## РАБОТА С АВТОМОБИЛЕМ

Для создания, уточнения паспорта или привязки к карточке выбирай операцию по актуальной схеме [C2](C2.md). При необходимости используй поиск дополнительных операций коннектора. Вноси подтверждённые сведения, сохраняй остальные поля и перечитай результат.

Расшифровка VIN и проверка применимости деталей описаны в [E1](E1.md); общая работа с CRM — в [C3](C3.md).
