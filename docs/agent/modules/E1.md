# E1 — VIN и подбор

E1 объединяет определение автомобиля, поиск номера детали, проверку кандидатов, подбор аналогов и оценку рынка. Выбирай необходимые инструменты в подходящем порядке; они доступны через [D1](D1.md).

## Вложенные возможности

- [E4 — Определить автомобиль](E4.md): профиль по VIN или номеру кузова. (Используй для расшифровки и уточнения модификации.)
- [E5 — Найти оригинальный номер](E5.md): каталоговые кандидаты OEM. (Используй для поиска номера нужной детали.)
- [E7 — Интернет-проверка детали](E7.md): сверка номеров и характеристик с публичными источниками. (Используй для проверки найденных кандидатов.)
- [E6 — Аналоги и применимость](E6.md): заменители и условия установки. (Используй для поиска и сверки аналога.)
- [E9 — Рыночная оценка детали](E9.md): ориентир по собранным сопоставимым предложениям. (Используй для исследования рыночной стоимости.)

## Источники и результат

[E2](E2.md) даёт расшифровку и данные PartsAPI; [E3](E3.md) — каталоги и предложения; [E8](E8.md) — публичный веб. Выбирай их по вопросу, без обязательного общего маршрута. Общие оценки confidence не являются измеренным процентом точности.

Каталожный номер и кросс остаются кандидатами до подтверждения применимости. Рыночный ориентир не подтверждает закупку, наличие или клиентскую цену. Общение и клиентская сделка — по [клиентскому скиллу](../../../.agents/skills/manage-autostop-client/SKILL.md), ценовая политика и операции с предложением — по [F4](F4.md).

Если запрошено несколько деталей, сохрани каждую позицию и её количество в результате; не своди весь запрос к одному найденному номеру.
