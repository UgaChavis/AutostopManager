# F5 — Заказы

F5 — заказы Store: выбранные позиции, количество, суммы, текущее состояние и сведения для выполнения заказа. Заказ продолжает согласованное предложение клиенту.

## ПОИСК И ЧТЕНИЕ

Используй `store_search` с типом `store_order` и `store_entity_context` для чтения выбранного заказа. Сверяй его связь с заявкой, позиции, условия и состояние оплаты по фактическим записям.

## ОФОРМЛЕНИЕ И ДЕЙСТВИЯ

- `store_quote_conductor` с переходом `order` — оформление по согласованному текущему предложению; параметры согласия и снимок состояния проверяй по контракту.
- `store_management_action` — доступная отметка готовности заказа.
- `store_owner_capabilities` и `store_owner_api` — поиск и вызов остальных доступных операций Store.

После действия перечитай заказ и сообщи проверенный следующий шаг. Обещание оплаты не является поступившим платежом; закупка, резерв и платежи требуют соответствующего разрешения. Подробности — в [F1](F1.md) и [навыке AutoStop](../../../.agents/skills/manage-autostop-store/SKILL.md).
