# E11 — Drom / Webbee

E11 — адаптер поиска объявлений Baza.Drom через Webbee. По текущей документации интеграция есть в коде, но выключена. Перед использованием проверь доступность; эта инструкция не включает источник.

## ПОСЛЕ ПОДКЛЮЧЕНИЯ

- `drom_start_parts_search` — начать ограниченный поиск по детали.
- `drom_get_parts_search` — получить состояние и результаты по идентификаторам возвращённой задачи.

Успешный запуск означает постановку задачи в очередь. Читай состояние существующей задачи до завершения; не создавай повторный поиск из-за задержки. Используй обезличенный запрос без полного VIN, контактов и секретов. Результаты остаются объявлениями для проверки наличия, применимости и условий продавца.

Подробнее о доступе, ограничениях и включении: [источники объявлений](../references/market-listings.md).
