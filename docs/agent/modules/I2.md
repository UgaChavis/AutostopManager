# I2 — Gmail

I2 хранит письма, цепочки переписки, вложения, черновики и метки подключённого почтового аккаунта. Доступен через I1; Gmail остаётся источником актуальных почтовых записей.

## РАБОТА С ПИСЬМАМИ

По запросу пользователя найди нужные письма и прочитай достаточный контекст. Для сводки выдели суть и необходимые действия. Вложения выбирай по метаданным родительского письма; не придумывай идентификаторы и не считай сокращённое извлечение полным документом.

## ПОДГОТОВКА И ОТПРАВКА

Подготовь текст или Gmail-черновик по задаче. Отправка требует поручения на отправку: проверь получателя, содержимое и вложения, затем независимо перечитай результат. Документы CRM готовь штатными средствами CRM и шаблонами AutoStop по [операционной инструкции](../references/crm-mail.md).

## ПОРЯДОК В ПОЧТЕ

Для порученной уборки архивируй письма с сохранением содержимого; корзину используй, когда запрошено удаление. Меняй только необходимые метки и письма. Переписку и вложения не сохраняй в общей документации или Git.

Доступные команды: [I1 — Gmail-коннектор](I1.md).
