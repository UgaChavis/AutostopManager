# C6 — Карточки ремонта

C6 — рабочие кейсы на доске CRM: ремонт, запись на приём или запрос на запчасти. Карточка связывает обращение, клиента, автомобиль, договорённости и следующий шаг.

## ПОИСК И ЧТЕНИЕ

- `agent_board_digest` — карточки и сводка доски.
- `agent_search` — поиск нужного кейса.
- `agent_entity_context` — описание, состояние, связи и история выбранной карточки.

## ВЕДЕНИЕ КЕЙСА

Используй `agent_board_workflow` для доступных операций с карточками; дополнительные действия ищи через [C2](C2.md). Перед созданием проверь существующие записи и связи, чтобы исключить дубль. По задаче обновляй описание, связи, метки, срок или состояние, сохраняя историю и остальные поля. После изменения независимо перечитай карточку.

Заказ-наряды описаны в [C7](C7.md). Для клиентского обращения основание создания карточки, колонку, описание сделки и запись определяет [клиентский скилл](../../../.agents/skills/manage-autostop-client/SKILL.md). Прямые поручения владельца по карточкам выполняй в их пределах по общим полномочиям.
