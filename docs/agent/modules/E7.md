# E7 — Техническое обслуживание

Каталожные позиции ТО и перечни расходников
Родитель: [E1](E1.md). Устойчивый ключ: `maintenance`.

## Входы

Maintenance brandId/modelId/typeId не TecDoc IDs.

## Отдельные инструменты

| Инструмент / карточка | Служба | Вызов |
| --- | --- | --- |
| [toMakes](../tools/partsapi-to-makes.md) | partsapi_ru · network_read · implemented | `partsapi_catalog_lookup · operation=toMakes` |
| [toModels](../tools/partsapi-to-models.md) | partsapi_ru · network_read · implemented | `partsapi_catalog_lookup · operation=toModels` |
| [toTypes](../tools/partsapi-to-types.md) | partsapi_ru · network_read · implemented | `partsapi_catalog_lookup · operation=toTypes` |
| [toParts](../tools/partsapi-to-parts.md) | partsapi_ru · network_read · implemented | `partsapi_catalog_lookup · operation=toParts` |

## Достаточность и границы

- toParts не является сроком замены; регламент требует источника и условий.
