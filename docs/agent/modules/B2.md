# B2 — Рабочий Telegram-аккаунт

B2 — рабочий канал AutoStop для общения с клиентами и владельцем. Доступен через B1 с выбором `--account work`; при включённом рабочем режиме личные входящие могут запускать Codex через B4.

## РАБОТА С ОБРАЩЕНИЕМ

Прочитай [Telegram skill](../../../.agents/skills/manage-owner-telegram/SKILL.md). Получи актуальный адресат через `monitor-target` для текущего события и прочитай диалог через `read`. Учитывай соседние сообщения, фото, голос и документы; не проси повторно уже предоставленные сведения.

Отвечай коротко и естественно: результат и следующий шаг. Для деталей, ремонта и записи используй нужные инструменты CRM и Store по [Store skill](../../../.agents/skills/manage-autostop-store/SKILL.md). Приветствие не требует обращения к CRM или Store.

## РЕЖИМ И УВЕДОМЛЕНИЯ

`scripts/set-work-telegram-duty.sh --status` показывает рабочий режим; `--enable` и `--disable` меняют его по поручению владельца. Обсуждение режима само его не включает. Закреплённого владельца определяй через `owner-target`, уведомления отправляй через `notify-owner` по текущему skill.

Проверяй выполненные отправки и изменения. После результата заверши ход. Технические детали: [Telegram и запуск по событию](../references/telegram-runtime.md).
