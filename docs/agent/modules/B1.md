# B1 — Telegram-мост

B1 связывает Codex с рабочим B2 и личным B3 Telegram-аккаунтами. Выбирай нужный аккаунт и команды по задаче; точные параметры проверяй через `--help` текущего bridge CLI.

## ПОИСК И ЧТЕНИЕ

- `dialogs`, `search`, `resolve-phone` — найти диалог или адресата.
- `read` — прочитать сообщения, включая исходящие.
- `download`, `discard-download` — получить временный файл медиа и удалить его после обработки.
- `monitor-target`, `monitor-read`, `monitor-context` — получить адресата и контекст текущего рабочего события.

## ОТПРАВКА

- `send`, `send-photo`, `send-document` — отправить текст, фото или документ.
- `owner-target`, `notify-owner` — определить закреплённого владельца и отправить ему уведомление.

Отправляй только по разрешённой задаче точному текущему адресату. Используй dry-run, свежий contract token и устойчивый idempotency key; затем независимо перечитай результат. При неизвестном исходе сначала выясни состояние отправки.

## СОСТОЯНИЕ

`probe`, `status`, `owner-status` показывают соединение и настройки. `monitor-status`, `monitor-events` показывают техническое состояние событий без чтения переписки.

CLI, аккаунты и служебные команды: [операционная инструкция Telegram](../references/telegram-runtime.md). Работа с диалогами и медиа: [Telegram skill](../../../.agents/skills/manage-owner-telegram/SKILL.md).
