# E9 — Рыночная оценка детали

E9 оценивает сопоставимые предложения по детали. `assess_part_market` через D1 рассчитывает ориентир по переданным сведениям; сам предложения не ищет.

## СБОР И ОЦЕНКА

Собери публичные предложения через E8, E3 или доступные источники объявлений. Сверь точный артикул, бренд, состояние, регион, цену и источники. Передай сопоставимые данные в инструмент по текущей схеме; используй диапазон и типичную цену только при достаточных независимых источниках.

`assess_avito_price_sample` отдельно описывает выборку Авито; её медиана не равна оценке рынка по независимым источникам. Если сведений мало, объясни пробел без выдуманной цены.

Оценка не создаёт предложение, заказ или карточку и не подтверждает наличие. Подробнее: [правила сегментов и источников](../references/part-market.md), [E1](E1.md), [E10](E10.md).
