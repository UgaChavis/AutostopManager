# C4 — Клиенты и телефоны

C4 — профили клиентов AutoStop в CRM: имя или организация, телефоны, другие контакты, комментарии и связанные автомобили. Через клиента можно найти его обращения и историю работы.

## ПОИСК И ЧТЕНИЕ

Используй `agent_search` для поиска клиента и `agent_entity_context` для чтения выбранного профиля и его связей. Сверяй данные с текущим обращением; перед созданием профиля проверь существующие записи.

## РАБОТА С ПРОФИЛЕМ

Для записи сначала проверь подходящий именованный workflow [C2](C2.md). Raw fallback ищи по точному имени: `create_client`, `update_client`, `link_card_to_client`; семантический discovery не возвращает write-операции. Получи схему через `get_raw_capability_schema`, затем вызови `call_raw_capability` с текущим `schema_hash`. Сохраняй только известные контакты и меняй поля в пределах поручения. После изменения перечитай профиль.

Связь с автомобилями описана в [C5](C5.md), команды — в [C2](C2.md). В клиентском обращении момент оформления и необходимые уточнения определяет [клиентский скилл](../../../.agents/skills/manage-autostop-client/SKILL.md); прямые поручения владельца выполняй в их пределах по общим полномочиям.
