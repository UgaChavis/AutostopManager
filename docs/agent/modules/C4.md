# C4 — Клиенты и телефоны

C4 — профили клиентов AutoStop в CRM: имя или организация, телефоны, другие контакты, комментарии и связанные автомобили. Через клиента можно найти его обращения и историю работы.

## ПОИСК И ЧТЕНИЕ

Используй `agent_search` для поиска клиента и `agent_entity_context` для чтения выбранного профиля и его связей. Сверяй данные с текущим обращением; перед созданием профиля проверь существующие записи.

## РАБОТА С ПРОФИЛЕМ

Для создания и изменения клиента найди подходящую операцию через `discover_raw_capabilities`, прочитай её схему через `get_raw_capability_schema` и вызови через `call_raw_capability`. Сохраняй только известные контакты и меняй поля в пределах поручения. После изменения перечитай профиль.

Связь с автомобилями описана в [C5](C5.md), команды — в [C2](C2.md), работа с клиентским кейсом — в [навыке AutoStop](../../../.agents/skills/manage-autostop-store/SKILL.md).
