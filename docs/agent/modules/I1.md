# I1 — Gmail-коннектор

I1 связывает Codex с подключённым Gmail. Выбирай команду по задаче; актуальные параметры и доступность проверяй в текущей схеме инструмента.

## ПОИСК И ЧТЕНИЕ

- `gmail_get_profile` — профиль подключённого аккаунта.
- `gmail_list_labels` — метки и счётчики.
- `gmail_search_emails`, `gmail_search_email_ids` — поиск писем.
- `gmail_read_email`, `gmail_read_email_thread` — письмо или цепочка.
- `gmail_batch_read_email`, `gmail_batch_read_email_threads` — чтение выбранных писем или цепочек списком.
- `gmail_read_attachment` — поддерживаемое вложение выбранного письма.

Операторы Gmail помещай в поисковый запрос; идентификаторы писем, цепочек и вложений бери из текущих ответов. Перед чтением вложения проверь его метаданные и поддержку формата.

## ЧЕРНОВИКИ И ОТПРАВКА

`gmail_list_drafts`, `gmail_create_draft`, `gmail_update_draft` работают с черновиками. `gmail_send_email`, `gmail_send_draft`, `gmail_forward_emails` отправляют почту по конкретному поручению после проверки адресата и содержимого.

## ОРГАНИЗАЦИЯ ПОЧТЫ

`gmail_archive_emails` архивирует цепочки; `gmail_delete_emails` переносит выбранные письма в корзину. Метки меняют `gmail_apply_labels_to_emails`, `gmail_batch_modify_email`, `gmail_bulk_label_matching_emails`; `gmail_create_label` создаёт метку. Выбирай операции только для порученных изменений и перечитывай результат.
