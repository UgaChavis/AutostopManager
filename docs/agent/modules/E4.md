# E4 — Определить автомобиль

E4 определяет автомобиль по VIN или номеру кузова и известным характеристикам. Используй `decode_vehicle_identity` для одного автомобиля или `decode_vehicle_identities` для списка через D1.

## ИСХОДНЫЕ СВЕДЕНИЯ И РЕЗУЛЬТАТ

Передай имеющийся идентификатор и известные характеристики по текущей схеме. Из ответа выбери профиль автомобиля, источники, уверенность и недостающие сведения. Разбери противоречия по марке, двигателю, году, рынку и модификации, если они влияют на задачу.

Если требуется только расшифровка, верни её результат. Для подбора детали используй профиль в [E5](E5.md); спорные характеристики оставляй неподтверждёнными.

Подробнее: [E1](E1.md), [источники E2](E2.md).
