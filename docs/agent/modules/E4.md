# E4 — Определить автомобиль

E4 определяет автомобиль по VIN или номеру кузова и известным характеристикам. Используй `decode_vehicle_identity` для одного автомобиля или `decode_vehicle_identities` для списка через D1.

## ИСХОДНЫЕ СВЕДЕНИЯ И РЕЗУЛЬТАТ

Передай исходный идентификатор клиента и известные характеристики по текущей схеме. VIN каталога не заменяет исходный VIN, год или комплектацию; совпадение VIN-префикса не подтверждает точный автомобиль. Для неоднозначного номера укажи `identifier_type`. Год выпуска, дата производства и модельный год — отдельные сведения. Из ответа выбери профиль автомобиля, источники, статусы полей и `missing_fields`. Уверенность — оценка полноты свидетельств, а не измеренная вероятность правильной расшифровки.

Если требуется только расшифровка, верни её результат. Непривязанный или чужой VIN в ответе закрывает использование этого ответа для точной расшифровки, а не независимый запасной маршрут [E2](E2.md). Для подбора детали используй профиль в [E5](E5.md); поле со статусом `disputed` исключается из согласованного профиля, его варианты остаются в свидетельствах. Реальное противоречие двигателя, модификации, КПП или других существенных характеристик закрывает точный подбор. `ready_for_family_lookup` разрешает ограниченное исследование семейства; готовность точной модификации проверяй отдельно. E4 не подтверждает применимость детали и не разрешает запись в CRM или Store.

В списке ошибка одного элемента возвращается в его строке, остальные позиции продолжают обрабатываться. Порядок и количество строк сохраняются. Лимит — 500 элементов; временно недоступные источники могут дать частичный результат. Не считай пропуск источника отсутствием автомобиля.
