# E4 — Каталоги и оригинальные номера

Дерево групп, статьи и OEM evidence
Родитель: [E1](E1.md). Устойчивый ключ: `catalog_parts`.

## Входы

TecDoc carId+carType+tree binding; articles использует strId из этого дерева.

## Достаточность и границы

- Article/cross/OE-reference не подтверждают оригинальный номер конкретного VIN.
- `search_articles` не обещает supplier ID: бери его из связанного `articles`/getArticles
  или подтверждённого входа. Если есть только article ID, выбирай заявленную article-ID операцию.
