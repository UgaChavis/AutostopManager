# E4 — Определить автомобиль

E4 — набор самостоятельных инструментов для VIN, WMI и японских номеров кузова. Codex выбирает подходящий источник, дополняет только недостающие или спорные сведения и прекращает поиск, когда данных достаточно для запроса. Обязательной последовательности нет; один вызов не запускает другие декодеры.

## ИНСТРУМЕНТЫ

Все десять инструментов доступны через локальный [A3 — CLI](A3.md); те же функции зарегистрированы в исходниках [D1 — MCP](D1.md). Доступность в установленном MCP проверяй по текущему `tools/list`.

| Инструмент | Короткая аннотация и источник | Режим |
| --- | --- | --- |
| `inspect_vehicle_identifier` | AutoStop: определяет тип идентификатора и проверяет структуру; источники не запрашивает | Локально |
| `decode_vin_vpic` | NHTSA vPIC: получает доступные сведения по VIN; покрытие автомобилей других рынков может быть частичным | Интернет |
| `decode_wmi_vpic` | NHTSA vPIC: справочные сведения о производителе по WMI; точную модель не устанавливает | Интернет |
| `decode_wmi_local` | AutoStop: подсказки производителя по локальному WMI-справочнику; страну завода не считает рынком | Локально |
| `vininfo_decode` | vininfo: базовый VIN-разбор и подробности поддерживаемых марок, с сохранением вариантов | Локально |
| `corgi_decode` | Corgi: расшифровывает VIN по подготовленному локальному снимку NHTSA; покрытие vPIC не расширяет | Локально |
| `vin_brand_details` | AutoStop: применяет ограниченные брендовые VIN-правила с источниками, годами и рынками; выдаёт кандидатов семейств | Локально |
| `decode_frame_local` | AutoStop: применяет имеющиеся правила японских кузовов; выдаёт только поддерживаемые семейства и варианты | Локально |
| `reconcile_vehicle_identity` | AutoStop: сопоставляет переданные результаты и известные характеристики, показывает пробелы и противоречия; запросов не делает | Локально |
| `decode_vehicle_batch` | AutoStop: обрабатывает список одним явно выбранным декодером, сохраняя результат каждой строки | По выбранному декодеру |

## ВЫБОР И РЕЗУЛЬТАТ

Проверка входа встроена в каждый инструмент; отдельный inspect необязателен. Для WMI передавай трёх- или шестизначный код. Неоднозначный идентификатор уточняй через `identifier_type` в inspect, vPIC VIN, брендовых/frame правилах и согласовании; vininfo/Corgi принимают полный VIN. Номер кузова не отправляй в VIN-декодер. По краткому коду или модельному семейству нельзя назначать двигатель, КПП и оснащение по умолчанию.

Самостоятельный декодер возвращает наблюдение `VehicleIdentityObservation` версии 1. Если нужны согласованный профиль и готовность к следующей задаче, передай выбранные наблюдения в `reconcile_vehicle_identity`. Источники одного происхождения, включая онлайн vPIC и локальный Corgi, не дают независимого подтверждения. Год выпуска, дата производства и модельный год остаются отдельными полями.

Batch допускает до 500 элементов и один из семи декодеров из таблицы: от `decode_vin_vpic` до `decode_frame_local`. Он не переключает источники; ошибка строки не отменяет остальные, порядок и количество результатов сохраняются.

`decode_vehicle_identity` и `decode_vehicle_identities` сохранены как составные инструменты совместимости. Они могут обращаться к нескольким источникам; для явного выбора используй самостоятельные инструменты выше.

## ЛОКАЛЬНЫЙ ЗАПУСК

JSON передаётся через stdin: `python -m autostop_manager.cli e4 <tool> --input -`. VIN не помещай в аргументы shell, постоянные журналы, Git или публичный веб-поиск. После установки дополнительного Python-набора и явной подготовки Corgi локальные декодеры не требуют сети или отдельного сервера. Подготовка и обновление данных — отдельные команды; при отсутствующей зависимости или базе скрытого сетевого fallback нет.

Расшифровка не подтверждает применимость детали и не разрешает запись в CRM или Store. Для деталей передай полученные наблюдения в [E5](E5.md). Контракт, статусы и ограничения — [vehicle-identity](../references/vehicle-identity.md); установка и команды — [manager-runtime](../references/manager-runtime.md); навигация — [E1](E1.md), внешние источники — [E2](E2.md).
