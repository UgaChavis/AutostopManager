# E4 — Каталоги и оригинальные номера

Дерево групп, статьи и OEM evidence
Родитель: [E1](E1.md). Устойчивый ключ: `catalog_parts`.

## Входы

TecDoc carId+carType+tree binding; articles использует strId из этого дерева.
Elcats принимает готовый vehicle_identity и название позиции либо связанный catalog_ref;
марка и профиль выбирают маршрут автоматически, без повторного decode.

## Достаточность и границы

- Article/cross/OE-reference не подтверждают оригинальный номер конкретного VIN.
- `search_articles` не обещает supplier ID: бери его из связанного `articles`/getArticles
  или подтверждённого входа. Если есть только article ID, выбирай заявленную article-ID операцию.

Elcats `list_parts` сохраняет исходный номер, позицию, количество и условия строки;
`lookup_candidates` сохраняет несколько подходящих схем, даты, PR/options и missing.
Реестр содержит все опубликованные марки, включая robots_disallowed/not_commissioned.
Flag=true не делает запрещённый маршрут доступным. OEM-кандидат не становится exact
VIN fitment без первичного подтверждения условий.
