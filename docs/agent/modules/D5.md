# D5 — Документация, навыки, обезличенный опыт

D5 описывает содержимое файловой части [D3](D3.md). Это материалы для выполнения задач, а не единый каталог записей с универсальной командой поиска.

- `AGENTS.md` — инструкция A2 с ролью и общими правилами; [A1](A1.md) помогает выбрать модуль.
- `docs/agent/` и другие документы `docs/` описывают операции, модули, каталожные источники и проверки. Перед применением технических деталей сопоставляй документ с текущим кодом и схемой инструмента.
- `.agents/skills/` содержит профильные инструкции и навигационные входы. [Клиентский скилл](../../../.agents/skills/manage-autostop-client/SKILL.md) — полный единый источник общения и ведения клиентской сделки; [B2](B2.md) выбирает его после определения роли. Модули сохраняют технические операции, данные, ценовую политику и проверки.
- [M2](M2.md) описывает постоянные технические журналы инженера; старую историю открывай по теме задачи.
- `private_knowledge/service_labor_experience.json` рядом с текущей SQLite Manager содержит обезличенные агрегаты опыта по работам, которые может использовать специальный инструмент оценки; по умолчанию это `data/private_knowledge/`. Частные отчёты и резервные копии не служат общей памятью агента.

Выбор и чтение материалов описаны в [D4](D4.md). Не помещай живые карточки клиентов, переписку, секреты и финансовые записи в общую документацию или память Manager.
