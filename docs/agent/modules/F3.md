# F3 — Каталог и склад

F3 — детали, складские партии и операции Store. Используй его для поиска позиции, проверки сведений о детали и доступного остатка.

## ПОИСК И ЧТЕНИЕ

- `store_search` — поиск по доступным типам `store_part`, `store_batch`, `store_warehouse_operation` и `store_sourcing_offer`.
- `store_entity_context` — подробности найденной позиции, партии или складской операции.

`store_sourcing_offer` доступен только через поиск: у него нет отдельного
`store_entity_context`. Условия предложения сверяй повторным текущим поиском.

Сверяй артикул, производителя, количество и текущие условия источника. Найденная деталь и её наличие сами по себе не подтверждают применимость к автомобилю; для этого используй [E1](E1.md).

## СКЛАДСКИЕ ДЕЙСТВИЯ

`store_management_action` содержит изменение места хранения партии. Другие доступные операции ищи через `store_owner_capabilities` и выполняй через `store_owner_api` по актуальному контракту [F1](F1.md). Меняй складские записи в пределах поручения и перечитывай результат; проверка остатка не разрешает резерв или закупку.
