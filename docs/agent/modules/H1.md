# H1 — Windsor.ai

H1 подключает Codex к рабочему Instagram AutoStop через инструменты плагина Windsor.ai. Выбирай действие по задаче и текущей схеме коннектора; наличие инструмента не подтверждает авторизацию аккаунта.

## ПОИСК И ЧТЕНИЕ

- `get_connectors` — подключённые источники и аккаунты.
- `get_fields` — доступные поля и таблицы выбранного источника.
- `get_data` — чтение данных по найденным полям.

Для H2 нужен ровно один текущий рабочий Instagram-аккаунт, указанный в [Instagram skill](../../../.agents/skills/manage-owner-instagram/SKILL.md). Идентификаторы аккаунта и полей бери из текущих ответов.

## ДЕЙСТВИЯ

`list_actions` показывает доступные операции и их схемы; `execute_action` выполняет выбранную операцию. Публикации и изменения комментариев требуют конкретного поручения владельца. После действия независимо перечитай результат; неизвестный исход сначала выясни перед повтором.

Проверяй доступ отдельно в интерактивной, CLI или фоновой среде, где выполняется задача. Технические сведения: [операционная инструкция Instagram](../references/instagram-runtime.md).
