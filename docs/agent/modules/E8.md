# E8 — Веб-шлюз

E8 ищет и читает публичные страницы для сведений о деталях и ценах. Инструменты доступны через D1; выбирай поиск или чтение по задаче.

## ИНСТРУМЕНТЫ

- `search_web_multi` — поиск публичных источников.
- `fetch_page_excerpt` — краткий текст выбранной страницы.
- `fetch_page_browser` — чтение страницы через браузер при готовом окружении.

Запросы составляй по артикулу и обезличенным характеристикам, без полного VIN, контактов и секретов. Сохраняй источник и смысл найденного; различай отсутствие сведений и ошибку доступа. Для большого исследования используй [J1](J1.md).

E8 даёт сведения для E7 и E9; применимость и актуальное предложение проверяются отдельно. Подробнее: [веб и каталоги](../references/web-research.md).
