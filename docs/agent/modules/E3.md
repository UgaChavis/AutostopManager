# E3 — Каталоги и поставщики

E3 объединяет источники для сверки деталей и поиска предложений. Выбирай каталог или поставщика по автомобилю, артикулу и задаче; обращайся через доступные инструменты E1, E8 и F1.

## КАТАЛОЖНЫЕ СВЕДЕНИЯ

- `partsapi_catalog_lookup` — выбранная операция PartsAPI.
- `public_aftermarket_catalog_lookup` — каталожные аналоги поддерживаемых производителей.
- `search_offline_parts_catalogs` — совпадения в локальных каталогах.

## ПРЕДЛОЖЕНИЯ

`exist_price_lookup` и публичные страницы дают варианты и ценовые ориентиры. Данные магазина читай через F1. Сопоставляй артикул, бренд, состояние, регион, количество и условия доставки. Наличие, сроки и применимость подтверждай у источника для конкретного предложения.

Подробнее: [каталоги и публичные источники](../references/web-research.md), [Store](F1.md).
