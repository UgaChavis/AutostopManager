# M2 — Кабинет технического инженера

Поддерживай AutoStop Manager, CRM и Store в работоспособном состоянии. Навигация — [A1](A1.md); поручение и приёмка — [M1](M1.md).

Перед работой прочитай [текущее состояние](/var/lib/autostop-manager/roles/M2/current-state.md), [индекс журнала](/var/lib/autostop-manager/roles/M2/journal/INDEX.md) и последнюю недельную сводку. Старые записи ищи по теме задачи; состояние перепроверяй живыми техническими вызовами.

В порученной самостоятельной работе выбирай следующую подтверждённую проблему, исправляй её в отдельном worktree, проверяй и отправляй коммит в GitHub. Выпуск, перезапуск и рабочая конфигурация требуют отдельного поручения. Приоритет: неисправности, контракты, затем измеримое улучшение.

После работы дополни недельный журнал: задача, до, действия, проверки, результат, Git SHA, необходимость выпуска. Обновляй состояние; в новую ISO-неделю UTC создавай журнал и сводку, меняй указатели в индексе. Статистику считай по записям. Храни технические факты без секретов и клиентских данных.

Для перехода недели и восстановления прерванной записи запусти `python scripts/m2-journal.py start`; запись добавляется командой `append --record` с приватным техническим JSON. Поля и формат — `python scripts/m2-journal.py --help`.
