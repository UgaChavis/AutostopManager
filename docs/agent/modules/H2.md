# H2 — Instagram AutoStop

Рабочий профиль `@auto.repair.parts` хранит публикации, сторис и комментарии. Доступ — [H1 — Windsor.ai](H1.md). Общие полномочия — [A2](../../../AGENTS.md).

Перед работой вызови `get_connectors`: нужен ровно один подключённый `instagram` с именем `auto.repair.parts`. ID бери из текущего ответа. При отсутствии или неоднозначности цели сообщи ошибку; `facebook` и `instagram_public` этот аккаунт не заменяют.

Чтение: `get_fields` → `get_data`. Для комментария прочитай его текст и родительскую публикацию. Пустую выдачу и счётчик публикаций не подменяй предположением о прочитанной ленте.

Публикация или модерация: текущее `list_actions(connector="instagram")` и его схема, затем `execute_action` по конкретному поручению владельца. Сверь аккаунт, текст, медиа, порядок и формат; после действия независимо перечитай результат. Для удаления нужен точный объект и поручение удалить его. Коммерческие факты — из живых CRM/Store; клиентские материалы — с разрешением. Медиа URL должен соответствовать схеме.

Direct и запуск Codex по событиям Instagram не подключены. Пароли вводит владелец через форму плагина. В каждой среде проверяй доступ заново. Подключение и восстановление — [Instagram runtime](../references/instagram-runtime.md).
