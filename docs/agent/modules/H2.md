# H2 — Instagram AutoStop

H2 — рабочий публичный Instagram-аккаунт AutoStop. Хранит публикации, сторис и комментарии; доступен через H1. Выбирай необходимые действия по поручению владельца и [Instagram skill](../../../.agents/skills/manage-owner-instagram/SKILL.md).

## ЧТЕНИЕ

Определи текущий рабочий аккаунт через `get_connectors`, затем выбери поля через `get_fields` и прочитай данные через `get_data`. Для комментария учитывай его точный текст и родительскую публикацию; проверяй фактические даты полученных записей.

## ПУБЛИКАЦИИ И КОММЕНТАРИИ

Через текущие `list_actions` и `execute_action` доступны предусмотренные коннектором форматы публикаций и действия с комментариями. Перед порученной записью сверь аккаунт, текст, медиа и формат; после — независимо перечитай результат. Коммерческие сведения проверяй в CRM или Store, клиентские материалы публикуй только с разрешением.

Direct и автоматический запуск Codex по событиям Instagram текущей интеграцией не предоставлены. Подключение, доступность и восстановление: [операционная инструкция Instagram](../references/instagram-runtime.md).
