# E13 — Стоимость работ

Ценовые свидетельства и расчёт по явной основе

- Неизвестный расход не ноль; pure calculation не читает experience/CRM.

## Следующий выбор

Используй готовое время либо [E12](E12.md). Для расчёта без acquisition выбирай calculate_work_price. Legacy estimate_repair_work_cost по умолчанию включает auto_research и internal experience; точные переключатели — в карточке.
