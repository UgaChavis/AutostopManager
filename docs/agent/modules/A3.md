# A3 — Терминал / CLI

A3 выполняет локальные команды, читает и изменяет файлы и возвращает вывод агенту Codex. Выбирай команды по задаче; терминал доступен через инструменты текущего приложения.

## ФАЙЛЫ И КОМАНДЫ

- `rg --files` — найти файлы; `rg -n` — найти текст в документации и коде.
- Открой нужный файл и прочитай относящийся к задаче фрагмент.
- Для команды проекта проверь её актуальную справку и рабочую папку. Учитывай код завершения и вывод.
- Если команда выполняется долго, продолжай работу с её текущей сессией.

## ПРОЕКТ И СЛУЖБЫ

Работай с AutoStop Manager в `/opt/AutostopManager`; CRM и Store находятся в отдельных проектах. Сохраняй пользовательские изменения. Изменение файла не означает обновление работающего сервера; выпуск и перезапуск выполняются по отдельному поручению.
