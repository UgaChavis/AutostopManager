# A3 — Терминал / CLI

A3 выполняет локальные команды, читает и изменяет файлы и возвращает вывод агенту Codex. Выбирай команды по задаче; терминал доступен через инструменты текущего приложения.

## ФАЙЛЫ И КОМАНДЫ

- `rg --files` — найти файлы; `rg -n` — найти текст в документации и коде.
- Открой нужный файл и прочитай относящийся к задаче фрагмент.
- Для команды проекта проверь её актуальную справку и рабочую папку. Учитывай код завершения и вывод.
- Если команда выполняется долго, продолжай работу с её текущей сессией.

## ПРОЕКТ И СЛУЖБЫ

Для разработки выбери актуальный checkout или worktree AutoStop Manager и перед правкой проверь `git rev-parse HEAD` и `git status --short`. `/opt/AutostopManager` также содержит действующие данные и настройки и не является автоматически актуальным исходным деревом. CRM и Store — отдельные проекты. Сохраняй пользовательские изменения. Изменение файла не обновляет сервер; выпуск и перезапуск требуют отдельного поручения.

Для live-операции выполни `readlink -f /opt/autostop-manager-releases/current`, затем прочитай `REVISION` и нужные документы по полученному физическому пути. Проверь manifest и active process отдельно. Source HEAD/dirty diff не заменяют installed REVISION. При смешанной работе запиши оба корня; используй абсолютные пути без смены cwd или новых runtime-копий. Для прямых source-команд используй проверенную development venv и убедись, что imports идут из выбранного checkout. Если скрипт требует собственную `.venv` worktree, соблюдай его контракт. Для installed imports соблюдай [runtime-контракт](../references/manager-runtime.md).
