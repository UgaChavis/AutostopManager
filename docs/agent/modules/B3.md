# B3 — Личный Telegram-аккаунт

B3 — отдельный аккаунт для личной переписки. Доступен через B1 с выбором `--account personal`; его входящие не запускают рабочий Codex через B4.

## ДИАЛОГИ И СООБЩЕНИЯ

Выбирай доступные команды `dialogs`, `search`, `read` по запросу пользователя. Перед обращением проверяй актуальную схему нужной команды через `--help` в установленном runtime личного аккаунта. Читай только необходимый для задачи контекст.

## ОТПРАВКА И МЕДИА

Для порученной отправки используй доступные `send`, `send-photo`, `send-document` с текущим адресатом и проверкой результата. Черновик ответа не разрешает отправку. Файлы медиа обрабатывай временно и очищай после использования.

`send-voice --peer <точный числовой ID> --file <outbox/file.ogg>` отправляет настоящий голос OGG/Opus, максимум 10 MiB и 10 минут. Подпись `--caption` необязательна. Outbox аккаунта — `0700`, обычный файл — `0600`; ссылки запрещены. Сначала dry-run, затем apply со свежим token и устойчивым ключом; результат подтверждается voice-флагом, MIME, длительностью и скачанными байтами. После отправки независимо перечитай этот диалог и удали временный файл. Неизвестный исход требует сверки, без нового ключа или слепого повтора. Команда недоступна рабочему аккаунту.

Личный аккаунт имеет отдельные session, службу и релиз; настройки рабочего аккаунта к нему автоматически не применяются. Технические сведения и bridge CLI: [операционная инструкция Telegram](../references/telegram-runtime.md).
