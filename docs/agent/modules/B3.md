# B3 — Личный Telegram-аккаунт

B3 — отдельный аккаунт для личной переписки. Доступен через B1 с выбором `--account personal`; его входящие не запускают рабочий Codex через B4.

## ДИАЛОГИ И СООБЩЕНИЯ

Выбирай доступные команды `dialogs`, `search`, `read` по запросу пользователя. Перед обращением проверяй актуальную схему нужной команды через `--help` в установленном runtime личного аккаунта. Читай только необходимый для задачи контекст.

## ОТПРАВКА И МЕДИА

Для порученной отправки используй доступные `send`, `send-photo`, `send-document` с текущим адресатом и проверкой результата. Черновик ответа не разрешает отправку. Файлы медиа обрабатывай временно и очищай после использования.

Команды `send` и `send-document` (только PDF) могут отвечать в явно разрешённую супергруппу: root-managed отдельный
EnvironmentFile личной службы задаёт `AUTOSTOP_PERSONAL_TELEGRAM_REPLY_GROUP_IDS` — список
точных канонических числовых peer ID через запятую. По умолчанию список пустой. Параметр
читает personal daemon при старте, не RPC и не окружение вызывающего CLI; work его
игнорирует. После изменения списка, в том числе отзыва разрешения, требуется согласованный
перезапуск личной службы; для отзыва сначала останови порученный мониторинг/отправки.

В разрешённой супергруппе обязателен `--reply-to-message-id` существующего обычного сообщения
этой же группы; `--peer` должен точно совпадать с её числовым ID. Название/username, канал,
обычная группа, бот, отправка без reply, фото и голос остаются закрыты. Используй прежние
dry-run/apply, свежий контекст, исходный ключ идемпотентности и независимый readback. Отправка
текста идёт без предпросмотра ссылок, результат проверяется как точный исходящий reply.
PDF отправляется из приватного outbox по прежним проверкам файла и подписи; контракт связывает
точную группу, reply, текст и метаданные вложения исходного сообщения, имя, размер и SHA-256 PDF.
Readback проверяет группу, ID, исходящее сообщение, reply, подпись и скачанные байты PDF по SHA-256.
Job/owner-маршруты этой возможностью не открываются.
Этот параметр сам не включает фоновый мониторинг, wake, расписание или клиентский процесс B2.

`send-voice --peer <точный числовой ID> --file <outbox/file.ogg>` отправляет настоящий голос OGG/Opus, максимум 10 MiB и 10 минут. Подпись `--caption` необязательна. Outbox аккаунта — `0700`, обычный файл — `0600`; ссылки запрещены. Сначала dry-run, затем apply со свежим token и устойчивым ключом; результат подтверждается voice-флагом, MIME, длительностью и скачанными байтами. После отправки независимо перечитай этот диалог и удали временный файл. Неизвестный исход требует сверки, без нового ключа или слепого повтора. Команда недоступна рабочему аккаунту.

Личный аккаунт имеет отдельные session, службу и релиз; настройки рабочего аккаунта к нему автоматически не применяются. Технические сведения и bridge CLI: [операционная инструкция Telegram](../references/telegram-runtime.md).
