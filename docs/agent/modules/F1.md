# F1 — Адаптер Store

F1 связывает AutoStop Manager с API магазина запчастей. Через [D1](D1.md) Codex читает данные Store и выполняет доступные действия; источником записей остаётся Store.

## ЧТЕНИЕ

- `store_runtime_status` — состояние соединения и готовность Store.
- `store_search` — поиск объектов магазина.
- `store_entity_context` — подробности одного объекта.
- `store_digest` — изменения; учитывай, что команда может продвигать служебную контрольную точку Manager.
- `get_store_analytics_report` — агрегированный отчёт по задаче.

## ДЕЙСТВИЯ

- `store_management_action` — доступные изменения заявки, партии или заказа.
- `store_quote_conductor` — работа с проценкой и переходами её процесса.
- `store_owner_capabilities` — поиск операций Store и их контрактов.
- `store_owner_api` — вызов выбранной операции API по актуальной схеме.

Выбирай инструмент и порядок действий по задаче. Перед записью прочитай текущий объект и проверь контракт; используй предусмотренные подготовку и dry-run, затем отдельно перечитай результат. При неопределённом результате сначала выясни состояние выполненного действия.

Подробные параметры и границы интеграции — в [руководстве адаптера](../references/store-api.md).
